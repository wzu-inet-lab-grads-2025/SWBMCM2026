# 运行记录｜双站等精度两方案对照

- **日期：** 2026-11-22
- **命令：** `nohup python3 -B -m checks.q2_scheme_compare`（默认写 `runs/q2/双站等精度两方案对照/`；本目录为复核后的归档副本）
- **输入：** `configs/q1.yaml` 的场地、五栋楼体与仰角区间；`checks.q2_geometry.load_scene` 的题面五车初始位与 T1–T3 告警。方案 A（离散网格构造）的 0.25° 可行性扫描与 10° 代表网格选择取自队友分支 `explore/b-first-round@30d54fa`，方案 B（净空取等构造）由 `d=5.4500002 m`、`a=sqrt(r0^2-d^2)` 解析给出。
- **输出：**
  - `two_schemes.csv`：逐车次站坐标、直达路长、行驶时间、仰角、车体净空；
  - `two_schemes_summary.csv`：方案级最长行驶、总路程、基线、交会角、RMSE、V5 净空；
  - `q21_schemes.pdf` / `q21_schemes.png`：等精度圆与两套站位、全场直达路线。
- **复核口径：** 45 cm 全程车体净空（`wall_clearance_m=0.45`）、单车行驶不超过 30 s、双站圆盘不重叠、交会角非共线。净空按原始矩形足迹减车盘半径 1.5 m 计算，允许相切。
- **结果：** 方案 A 最长行驶 13.306469340 s、总路程 54.191542174 m、V5 净空 0.467874366 m；方案 B 最长行驶 13.293760117 s、总路程 54.103788708 m、V5 净空 0.450000200 m。两套站对的基线均为 8.229012248 m、交会角 90°、一阶 RMSE 0.143623358 m。
