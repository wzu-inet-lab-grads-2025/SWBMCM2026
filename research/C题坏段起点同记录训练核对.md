# 逐手遮挡标签起点：同记录历史运动核对

## 结果读取前固定的规格（2026-11-20）

这是队伍已有腕运动、掌面转动候选的**描述性核对**，不是正式模型，也不是重复既有全池速度二档实验。开始工作时基线为 `50981ff`，当前 worktree 获用户授权继续；不提交、不推送。

1. **输入边界**：仅官方 `train` 的 EgoPro / EgoStandard。复用官方索引与元数据校验、整数纳秒腕点对齐、掌部五点读取和历史尺度函数；不读取验证/测试记录内容，不读取 Demo 原始记录，不扫视频。官方划分及位置索引只用于选择训练记录。
2. **标签**：`problem_type` 的 `left:occlusion` / `right:occlusion` 是逐手自然遮挡**标签代理**。同手连续原因段在间隔 >50 ms 处断开。仅前一点联合 `is_bad=False` 的相邻首点叫“已见正常→遮挡起点”；记录边缘/间隔、前点同手其他坏原因、前点联合坏但本手未列原因分别计数。最后一种是未知，不是正常。起点同时含本手其他原因者保留并单列，不把“有 occlusion”改成“纯 occlusion”。
3. **历史与可见性**：对目标点 `j`，锚为 `j−1`，取锚前 200 ms 处或之前最近的存储点，直至锚，故真实跨度至少 200 ms、最多多一个采样间隔；目标与锚间隔也须 (0,50] ms。全历史联合显式正常、双腕有限且非全零；目标手 0/5/9/13/17 五点有限、无全零点，定义法向的两向量夹角正弦 ≥0.1，历史腕至中指 MCP 距离为正。目标点坐标、起点之后坐标不参与特征或合格性判断。这里的“可见”仅指历史数值及显式标签可用，不证明相机视野或物理精度。
4. **两个既有候选量**：历史腕轨迹总长度 / 实际历史时长 / 历史腕至中指 MCP 距离中位数，单位 `L/s`；有序叉积法向的相邻夹角总和 / 实际历史时长，单位 `deg/s`。不作速度分档、不调整角度阈值、不补值、不平滑、不拟合。尺度只来自各自历史。
5. **固定 1:2 双向匹配**：候选对照目标点必须显式联合正常，其历史满足同一规则。与事件同记录、同手、同记录相对时间四分区（以整条记录首末时间等分），历史点数完全一致，历史跨度及锚到目标年龄分别相差 ≤1 ms。分别在事件前、后闭区间 [1,5] 秒内取最近者，各一个；缺任一侧则事件不评分，分列只缺前、只缺后、两侧均缺。不以运动数值匹配。不同事件可复用对照，公开复用计数；同一事件两个对照历史互不重叠。不另要求对照未来保持正常。
6. **单位和汇总**：每个合格手起点等权，对照特征取其前后两点均值；报告事件减对照差、中位数、正差计数，继而先在记录内平均事件差、环境内等权记录、最后等权有匹配的环境。不把左右同时起点或同记录多次起点当成独立样本。预定附报分别对前、后对照的差、逐个删去有匹配环境后的同一宏平均范围，不据此重选规格。记录/环境无起点者保留分母但不填零差。
7. **可能推翻的观察**：同记录正常对照有相同或更大运动；正差只来自少数记录/环境，前后对照方向相反，删一个环境即翻向，或大量起点因正常历史/双向对照不足被排除。这些都削弱“运动增加能普遍提前提示自然遮挡”的解释。即使正差稳定，仍不能从离线匹配推出因果关系、在线误报率或校准可靠性。

匹配使用未来正常对照及整记录时间四分区，只用于离线描述，**不是可部署预警流程**。同记录可固定来源、操作员、环境、相机/坐标系等静态差异，但不能固定局部任务阶段、物体接触、手在画面中的位置或标签标注延迟。

## 执行结果：总体方向不稳定，不支持统一单调解释

**34 个匹配手起点仅来自 6 条记录、5 个环境。腕速的环境等权差为 −0.049 L/s，掌面角路径速度为 +0.215 deg/s；逐个删去环境，两者的宏平均都能翻向。** 左手腕速有局部正差，右手则相反。结果适合限定候选的适用范围，不适合宣称已找到了普遍的遮挡诱因或可靠性函数。

## 对 Q1 影响因素与可靠性的含义

1. **已经出现的反证**：同质量/历史、同记录同手对照下，很多正常时刻的运动并不小；整体环境方向分裂，宏均值对去掉一个环境敏感。它削弱了“仅靠近期运动大小即可普遍提前提示遮挡”的描述，不证明运动毫无作用。
2. **标签可靠性不等于物理可靠性**：`occlusion` 是质量清单中的逐手原因，不给出遮挡比例、被遮关节、真实空间误差或标注延迟。另一手单独标坏时，本手未列原因仍是未知。历史显式正常和数值完整也不能证明无跟踪抖动；角路径尤其可能累计估计噪声。
3. **仍未消除的混杂/选择**：记录内匹配固定静态来源、环境、操作员和坐标背景；四分区与近时对照只能粗略约束作业阶段。物体接触、画面边缘、相机运动、任务切换都未观测。后对照可能是遮挡后的动作反应，不能视为未受事件影响；联合正常历史条件排除了另一手坏时的样本，也排除了短间隔复发，估计对象因此变窄。匹配没有按运动值择优，但无法保证可交换性。
4. **可推翻本轮谨慎结论的新观察**：若在预先固定、具有更多独立记录/环境的同类对照中，左右手及多数环境都出现一致、足够大的正差，且在明确标注延迟、接触阶段等边界后仍保持，才会增强运动候选的通用解释。反过来，补充阶段/视野背景后局部左手差消失，或其方向在独立环境反转，会进一步削弱它。本轮不据这些数值选正式阈值、不打开留出集。
5. **不作的结论**：1:2 选样比例不是遮挡发生率；这里没有概率模型、预测阈值、误报/小时、召回、校准、显著性检验或因果效应。只有匹配事件前的候选运动描述，不能取代正式的在线可靠性评估。

import pandas as pd
from experiments.c_q1_onset_context import COUNT_FIELDS, METRICS
