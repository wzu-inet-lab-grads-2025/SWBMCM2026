# 相同预算和延迟下，回访时机的训练对照

一次双腕包花费 2 个示例费用单位，0.5 秒后披露，两个允许请求的方法均限每窗一包。固定“保持最近已收到位置”的预测器，比较窗首请求与距上次可靠采样满 1 秒时请求。后者取首个达到该时间的真实采样点，提交当前预测后请求，延迟届满后才将该源时刻的双腕点交给预测器。该时机为读数前指定的训练对照。

| 训练条件 | 请求 / 回执 | 总费用 | 在途时间合计（秒） | 平均左 / 右腕误差（厘米） | 平均左 / 右腕相对误差 |
|---|---:|---:|---:|---:|---:|
| 不回访 | 0 / 0 | 0 | 0 | 19.79 / 20.93 | 2.323 / 2.454 |
| 窗首请求 | 328 / 328 | 656 | 164 | 19.42 / 20.54 | 2.279 / 2.409 |
| 满 1 秒请求 | 328 / 328 | 656 | 164 | 15.83 / 16.90 | 1.858 / 1.982 |

所有条件共用显式正常的 Pro/Standard 训练记录，328 个非重叠窗、28 条记录、10 个环境、每手 19,639 个评分时刻。每窗 1 秒历史、2 秒人工遮挡，相对误差均使用遮挡前锁定的逐手 0–9 尺度。记录内按时刻取平均，再在环境内等权平均记录，最后在环境之间等权平均。每次试验的结算按窗累计，每包计一次。[按记录和环境的底表](q2_diagnostic/train_packet_value.csv)

满 1 秒请求相对窗首请求，左、右腕的全窗平均误差各下降 3.59、3.65 厘米，两个方法的费用和在途等待相同。10 个有窗训练环境的左右手环境均值均下降。窗首能较早收到包，包的源时刻与最后可靠采样通常仅隔一个采样间隔。满 1 秒请求约在 1.5 秒时收到包，披露的点更接近窗末的运动状态。前后两种收益由同一批参考腕点计算，范围限于当前预测器、窗长和资源口径。正式请求时机还需要队伍确定应用损失与延迟范围，再进行留出比较。

这项实验直接度量特定行动下的误差变化。要评价按熵请求是否有额外价值，须另有用当时可见数据估计的概率分布，并在相同费用、延迟、样本和预测器下与两种固定时机配对。预先约定误差容差时，还可比较超差时刻数与首次超差前回执是否送达。验收时用合成纳秒时钟检查请求落在真实采样、两手同包、准确到期披露和一次扣费。[诊断脚本](../experiments/c_packet_value.py) · [合成验收](../checks/test_c_palm_and_information.py)
