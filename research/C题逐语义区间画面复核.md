## 抽样和判读口径

抽样单位是 `source_segment_index.csv` 的一个官方区间。以记录 UUID 对接官方划分，在原始 JSON 或 CSV 中逐项核对该段起点、终点及英文描述。EgoDemo 使用 Parquet 中原存储的 `timestamp` 和从零递增的 `frame_index`。EgoPro 和 EgoStandard 用首条语义标注的 `header.ts` 减去该条起点得到时间原点，在整数纳秒域从轨迹时间戳中减去原点，再换算为秒；视频旁车的 `video_timestamp_ns` 与轨迹行逐一对齐。视频展示帧号与轨迹行的全量核验见[全视频解码与时钟核查](C题全视频解码与时钟核查.md)。

只在 `start_s ≤ t < end_s` 中选帧。前、后分别是实际落入的第一帧和最后一帧，中间是两者之间距区间算术中点最近的一帧（等距取较早者）。按记录汇集所需展示帧号，对每个头左源视频单次顺序解码。私有清单保留全部英文原文、三个源时刻、帧号及相应图片；每个区间在图册中独占一行，按时间从左到右排列。单图保留 960 像素宽和原始宽高比，支持回看放大。

逐段比对两个问题。**物体**判断原文的对象、包装及用于区分对象的颜色、字样等限定是否可辨。**动作**判断原文的主动作、起落位置、方向、数量及涉及的先后关系有没有画面支持。陈列任务名称和相邻区间的文字不充当本段证据。评级按下表执行，总评取两维中证据较弱的一档，任一维有直接反证则总评为明确矛盾。

| 等级 | 证据要求 |
|---|---|
| 可见支持 `visible` | 能辨出该维度的主要对象或动作。跨帧可定位同类目标的持握和两端状态，足以支持原文所述操作。 |
| 部分支持 `partial` | 有可指认的正面线索，仍有关键限定无法核实，例如能见瓶形但看不清品名、能见移位但无法区分拉动与翻转、能见标签朝前但无法确认操作者核对了价格。 |
| 画面证据不足 `insufficient` | 本段样本不能识别目标，或仅有陈列背景、手在附近等非特异线索，尚无足够依据支持主动作。 |
| 明确矛盾 `contradiction` | 画面中的目标可以唯一对应，且可见属性或动作与原文互斥。目标出框、只拍到动作一端、字样不清和无法确证均不构成直接反证。 |

训练、验证、测试均按同一规则用于回顾性描述。公开定位例仅取训练集。审核者已见过抽样测试画面，测试描述与判读均不用于选择模型、调参或报告预测性能。这项工作是逐区间三时刻的 AI 读图核验；连续视频中每一帧的动作、精确边界、商品后台身份及主观意图超出其可确认的范围。

## 本地复核入口

在仓库根目录、已解压 C 题附件的环境中执行。需要 FFmpeg、Pillow、NumPy、pandas、PyArrow。脚本启动两个视频工人，每路解码、过滤和编码各限单线程。本次在 Linux 的两个允许 CPU 上运行。再次抽帧会更新同名索引及图片，逐段笔记另存。

```sh
PY=/mnt/disk/zhoutianyu/miniconda3/bin/python
export OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 ARROW_NUM_THREADS=1
nice -n 10 taskset -c 17,18 "$PY" -B experiments/c_all_segment_review.py
xdg-open runs/c_dense_segment_review/pages/01.jpg
nice -n 10 taskset -c 17,18 "$PY" -B experiments/c_all_segment_review.py --extra
taskset -c 17,18 "$PY" -B experiments/c_all_segment_review.py --aggregate
cmp runs/c_dense_segment_review/review_summary.csv research/c_dense_audit/review_summary.csv
```

`runs/c_dense_segment_review/manifest.csv` 以 `ordinal` 对应图册行号，以 `unit_id` 对应官方区间。`images/` 保存单张图，`pages/` 保存图册。`notes.csv` 每段一行，列为 `ordinal,unit_id,object,action,observation`，最后一列写下可具体指出的物体、姿态变化或判读困难。`--extra` 读取私有 `extra_requests.csv` 的 `ordinal,view,fraction`，根据请求比例取最近的区间内源时刻，生成 `extra_manifest.csv` 和 `extra/`。在新检出环境中可重建全量头左图册，再按图填写独立判断。精确重放本次补图和计数需要本地补图请求及逐段笔记。`--aggregate` 将笔记对回官方全集、检查图片及半开区间约束，再生成有原文和证据的私有 `reviewed.csv` 与公开汇总的本地副本。
