# C 题逐帧画面变化与官方动作边界

**官方动作交界附近，头部和腕部画面的局部变化平均增强。** 头双目 279 个可匹配边界中，196 个的局部变化高于前后同段对照，双腕为 55/82。对头双目，真实边界相对段中伪边界的额外增量为 **+2.39**，环境簇 95% 区间 **[+1.30, +3.62]**。双腕对应 **+1.92 [−0.58, +4.48]**，仅覆盖 7 个环境。头部边界也伴随平均 **+11.16°/秒** 的头相机转速增量，像素变化混有相机自身运动。结果支持动作交界附近常有画面变化，单个动作含义、边界准确到哪一帧以及每段作业是否成功仍需独立语义证据。[边界汇总](c_dense_audit/semantic_boundary.csv) · [伪边界对照](c_dense_audit/semantic_contrasts.csv)

## 时间与分母

以原始记录元数据 UUID 匹配官方划分，以 `(episode_uuid, source_segment_index)` 对接原始语义行和官方源段索引。逐项比较段序、起止十进制秒、英文描述、样本目录、来源和划分，使用全部 349 段，包括时长短于 1.2 秒的 6 段。画面特征只由已解码的像素计算，原始英文仅参加索引一致性检查。

- Demo 按连续帧号取 Parquet 存储的 float32 源秒值，将其精确转换为有理数。Pro、Standard 将每路 `video_timestamp_ns` 与同记录五张位姿表及质量表按行核对，使用第一条语义消息的 `header.ts − start_time × 10⁹` 作统一原点。先在整数纳秒域相减，再与十进制端点比较。
- 每路 FFmpeg 保留展示顺序，原生帧的序号、整数 PTS、帧尺寸、像素格式和流时基逐帧核对，包 PTS 排序后与展示 PTS 一一相等。在源时钟上以 `[开始,结束)` 分段。第二遍从精确源时间逐帧作十进制直接比较，核对半开归属、闭区间成员数和精确端点标志。另用首帧对齐的有理数 PTS 重新分段，度量错用展示时钟的影响。

69 条记录、184 路视频包含 349 个唯一语义段和 908 个「段、视角」组合。帧覆盖率为 **99.541%**，记录时刻覆盖率为 **99.538%**。280 个内部边界均为上一段结束且下一段开始的同一个时间，展开为 724 个视角边界。每路头相机覆盖 349 段、280 次换段，每路腕相机覆盖 105 段、82 次换段。半开覆盖外的 820 帧都在末段右端点或其后，88 帧恰在末段右端点，另 732 帧严格在其后，对应 36 和 269 个记录时刻。内部端点恰落在采样时刻时，半开定义只分入右段。跨段相邻帧对归到右段首帧，保留其左段末帧的索引。所有原始起止均落在十进制 0.1 秒网格上，这一网格和实际采样间隔共同限制了对物理动作切换时刻的解释。[覆盖汇总](c_dense_audit/semantic_coverage.csv)

**错用 PTS 会改变 492 帧的段归属**，其中 94 帧在覆盖内外之间切换，另外 398 帧仍有语义覆盖但换了段。记录时刻去重后分别是 207、38 和 169 个。Demo、Pro、Standard 的归属变化时刻数分别为 18、35 和 154。半个帧周期以内的时钟偏移足以跨过精确半开端点。[本次归属对照](c_dense_audit/semantic_coverage.csv) · [展示时钟相对源时钟的偏差](c_full_audit/video_clock.csv)

## 固定的画面指标

从每个原生视频重新解码，面积缩放为 144 × 112、全范围 8 位 YCbCr 4:4:4。各帧保存中央 128 × 96 的 8 × 6 个等面积分块，每块 16 × 16，三个通道分别取均值。运动依据同文件的相邻亮度帧，两侧始终取相同大小的中央有效区。头相机原生尺寸为 1920 × 1456，腕相机为 1920 × 1536，因此两个视角每个缩小像素对应的原始垂直尺度有差别。[原生视频规格](c_full_audit/video_format.csv)

1. **画面整体平移。** 在两帧亮度图上分别减去均值、乘二维 Hann 窗，计算归一化互功率谱的逆变换。在横纵各 ±8 个缩小像素内取相关峰，对齐前帧。从对齐差图减去有符号亮度差的中位数，各块取平均绝对差。只在分块差值的中位数降低时采用平移，否则取零位移。保留横纵位移、亮度偏移和全部 48 个残差。此处的平移描述画面共同变化，场中大面积物体的运动也会产生这一信号。
2. **主要指标 `local`。** 对相邻帧的 48 个分块残差取 P90，除以 `30 × 源帧间隔秒数`，换算为每 1/30 秒的亮度级变化，再在窗口内按实际时间加权。`raw` 是同一中央区未补偿的像素平均绝对差，使用相同的时间归一。`shift` 为采用的整体位移模长除以源帧间隔，单位为缩小像素/秒。`head_omega` 取同步头相机姿态四元数归一化后相邻短弧夹角除以源帧间隔，单位为度/秒，仅作为独立的整体运动参照。
3. **外观指标 `appearance`。** 每帧的 48 × 3 个块均值保持至下一源时刻。分别计算中心前、后各 0.20 秒的时间加权均值，对两侧差取绝对值、块内跨三个通道平均，再在 48 块中取 P90，单位为 8 位通道值。此量保留固定画面位置，因而包含转头等导致的构图变化。`single_local` 单独读取夹住中心时刻的一对帧，若中心正好是采样时刻，则用该帧与其前帧。

在每个源帧时刻均计算上述前后窗口，保留文件首末缺少完整窗口的状态。按相邻对统计时，首帧单列，其余每对按同段、跨段、离开末段、两端均在覆盖外互斥计数。同段帧对另用帧对中点至最近内部边界的距离分档。每记录有 2–23 段，均可计算这个距离。[所有相邻帧对](c_dense_audit/semantic_pairs.csv)

178,328 个相邻视角帧对中，同段 **176,784**、跨段 **724**、离开末段 **174**、两端均在覆盖外 **646**。176,240/178,512 个视角帧时刻具有完整前后窗口，余下 2,272 帧仍计入时钟和逐帧台账。整体平移补偿在 52,022 对上采用了非零位移，16 对的采用位移碰到搜索范围边缘。合成核对复现了已知的二维整像素平移、全局亮度偏移和一个分块上的独立变化。另用非均匀采样的阶跃例验证了时间加权积分。局部 P90 对仅限极少数块的细小动作可能不敏感。[全量分母](c_dense_audit/semantic_coverage.csv) · [合成核对实现](../experiments/c_dense_semantic_compare.py)

## 边界、时间匹配与不确定性

每个内部边界取前后各 0.20 秒的完整窗口，与同一记录、同一视角、中心前移和后移各 0.60 秒的两个窗口配对。要求前对照涉及的所有帧都在左段，后对照涉及的所有帧都在右段，包含与窗口有正时长交集的帧对两端。每个边界等权，配对差取中心减去两侧对照的均值。保留额外的 ±0.30 秒中心错位剖面。另仅移动中心一个实际源帧间隔，对照窗口固定，计平均变化及各边界绝对变化的 P50、P95。所有纳入的真、伪中心和错位窗口都用「直接求帧间隔交叠时长」复核累积积分结果。[窗口支持数](c_dense_audit/semantic_support.csv) · [错位剖面](c_dense_audit/semantic_offset.csv) · [一个源帧间隔的敏感性](c_dense_audit/semantic_jitter.csv)

伪边界固定在相邻两段中较长一段的中点，等长时选左段。中心、两个对照及其全部支撑帧均须落在该段内。真实与伪边界效应比较采用两种设计均有效的同一组原始边界。相邻边界可能复用同一伪中心，表中列出不同中心数。整体运动敏感性取中心与两侧对照的 `shift` 均相差至多 15 个缩小像素/秒的边界。该筛选只能控制估计到的平移速度，旋转、视差、遮挡、画面深度及曝光仍可贡献残差。

头左、头右、左腕、右腕各有独立结果。同记录同时刻先取两眼均值或两腕均值，形成头部和腕部结果，再以四路齐备的边界计算腕减头配对差。抽样单位是官方环境，每次有放回抽取原组环境数，带入其全部记录、边界和配对，重算边界等权均值。以固定种子 20261121 重采样 3,999 次，取 2.5% 和 97.5% 分位数。区间描述附件内关联对环境构成的敏感性。按同一固定规则在三个官方划分上开展描述性核验。[边界与同段对照](c_dense_audit/semantic_boundary.csv) · [配对差的差](c_dense_audit/semantic_contrasts.csv)

可见的 280 个内部边界均保留了实际跨段帧对。一个头部边界的同段对照窗超出段界，窗口配对总计使用 722/724 个视角边界。未补偿的 `raw` 配对均差为头双目 +2.85 [1.71, 3.91]、双腕 +1.71 [0.79, 2.64]。块级 `appearance` 配对均差分别为 +2.38 [1.65, 3.06]、+1.59 [0.45, 2.95]。在相同 82 个四视角边界上，头双目 `local` 增量为 +2.97，双腕为 +2.89，腕减头为 −0.07 [−1.04, 1.09]。不同相机覆盖的记录构成有别，直接相减全体头和全体腕的均值会混入样本构成差异。[边界汇总](c_dense_audit/semantic_boundary.csv) · [同事件对比](c_dense_audit/semantic_contrasts.csv)

**段中也有画面变化。** 真实与伪设计共同有效的 273 个头部边界上，`local` 的真实边界增量 +3.68，伪边界增量 +1.29，配对差为 +2.39 [1.30, 3.62]。对应的 202 个不同伪中心中有一部分被相邻边界共用。腕部的 80 个共同边界对应 61 个不同伪中心，真实增量 +2.81，伪增量 +0.89，差为 +1.92 [−0.58, 4.48]。`appearance` 的真伪差也在头部更明确，头双目 +1.85 [1.00, 2.54]、双腕 +1.61 [−0.11, 3.58]。实际获得较高变化值的同段帧可以是段内动作进展的一部分。[真伪边界同组配对](c_dense_audit/semantic_contrasts.csv) · [可用伪中心数](c_dense_audit/semantic_support.csv)

**相机运动混杂。** 在头左、头右各 66,001 对帧中，`raw` 与对应头相机角速度的 Spearman 相关分别为 0.766、0.768，局部残差 `local` 与角速度仍达 0.743、0.745。真实边界的头双目整体图像平移速度比对照高 +11.99 缩小像素/秒，姿态角速度高 +11.16°/秒。在平移速度相近的子集中，头双目 `local` 增量为 +2.20 [1.30, 3.39]（107 个边界），对应角速度仍多 +3.85°/秒。双腕的相近平移子集只余 28 个边界，增量 +2.10 [−0.25, 5.69]。当前整像素平移可以抵消部分共同位移，仍不足以将残差归因于某只手或某件商品。上述全帧相关按帧加权，长记录权重较大。[全帧相关](c_dense_audit/semantic_pairs.csv) · [平移匹配与相机姿态](c_dense_audit/semantic_boundary.csv)

**边界时刻的定位精度。** 窗口中心按 −0.60、−0.30、0、+0.30、+0.60 秒平移时，头双目的 `local` 均值依次为 10.53、13.68、15.70、15.14、13.57。双腕对应值为 11.32、14.56、16.64、17.58、16.16，在 +0.30 秒处仍高于官方边界。在真实边界中心仅偏移一个实际帧间隔时，头双目窗口均值改变 −0.09 / +0.05，双腕 −0.12 / +0.17。绝对变化 P95 分别为 1.36 / 1.32 和 1.73 / 1.76。只看单个帧对时，同一项 P95 上升为头部 4.56 / 4.12、腕部 5.40 / 5.67。这些宽峰和不对称性支持邻域关联，无法单凭峰值反推出精确的动作切换帧。[时间错位](c_dense_audit/semantic_offset.csv) · [一帧敏感性](c_dense_audit/semantic_jitter.csv)

## 复现和段级回查

在仓库根目录执行。使用 Python 3.11 环境，NumPy 1.26.4、SciPy 1.17.0、pandas 2.3.3、PyArrow 22.0.0、FFmpeg/ffprobe 4.4.2，另需 GNU `timeout`。本机示例将三个单线程解码 worker 及其特征计算限制在三个逻辑 CPU。重复全解码时指定新的私有目录，避免覆盖现有运行。

```bash
PY=/mnt/disk/zhoutianyu/miniconda3/envs/LLM4AD/bin/python
export OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 MKL_NUM_THREADS=1
taskset -c 8-10 "$PY" -B experiments/c_dense_semantic_clock.py --workers 3 --run-dir runs/c_dense_semantic/reproduction
taskset -c 8-10 "$PY" -B experiments/c_dense_semantic_compare.py --run-dir runs/c_dense_semantic/reproduction --out runs/c_dense_semantic/reproduction/aggregate
for f in research/c_dense_audit/semantic_*.csv; do cmp "$f" "runs/c_dense_semantic/reproduction/aggregate/$(basename "$f")" || exit 1; done
```

本次完成一次全量解码，并从保存的逐帧特征重新计算了全部配对和汇总，重算后的七份表均与公开副本逐字节一致。另外回读 184 张逐帧表，按 `unit_id` 重新计算 908 个段视角的首帧、末帧和总帧数，逐项与段表相等。

本次的私有运行根目录为 `runs/c_dense_semantic/`，其中 `views/view_NNN.json` 给出该 `file_id` 的来源、UUID、相机、视频相对路径和官方段键，`.npz` 保留整数 PTS、原始源时钟、半开归属、闭区间计数、48 块逐帧外观及相邻残差。`frames/view_NNN.parquet` 每帧一行，记录段键、帧号、源秒、帧对类型、与内部边界的距离、完整窗口得分。`segment_views.parquet` 可按官方 `unit_id` 或 `(episode_uuid, source_segment_index)` 定位，含每个现有视角的首末帧号及段内变化。`boundary_views.parquet` 以左右 `unit_id`、`file_id` 和 `protocol` 定位真实及伪边界，含各窗口的实际帧范围、数值和可用状态。私表均在 Git 忽略目录。公开 CSV 只保留集合统计。[逐帧源时钟与图像提取](../experiments/c_dense_semantic_clock.py) · [独立复核与配对汇总](../experiments/c_dense_semantic_compare.py)
