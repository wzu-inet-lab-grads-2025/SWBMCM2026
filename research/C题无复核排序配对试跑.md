# 第三问无付费复核的排序基线

**9 对验证试跑、18 次回放均通过账本核对。** 本轮按队伍授权选取先到先服务（FCFS）和最早交期优先（EDD）作为试跑基线，只改变可执行作业的排序键。S1 首个种子 `2026111700` 的 8 项来源只抽取一次，两种排序共用这份分配。首对加权按时率为 75.00% / 93.75%，费用为 21.411 / 21.493。复算通过后继续 S1、S2、S3 的其余配对，首对只计一次。预先固定的验证种子为 `2026111700`、`2026111701`、`2026111702`，全部采用名义映射。

**共同规则。** 从训练集冻结的 P / A / L 原始标注时长中位数为 4.0 / 3.2 / 3.6 源秒。用 `b=max(0.2, α×类别中位数+β)`，在 `α=1, β=0.5` 时分别预留 **4.5 / 3.7 / 4.1 情景秒**。设备可用时，候选作业必须已释放、未执行且前置全部完成。设当前位置到作业区的距离为 D，服务开始时刻 `s=t+D+0.5`。须同时满足 `s+b≤H` 和 `2+0.1b+0.2D≤剩余预算`。入选判断只使用决策时已知的条件。FCFS 按释放时刻、EDD 按交期升序，两者平局均按 `job_id` 升序。只要有候选就立即执行，否则等到 H 之前的下一次释放。没有候选也没有后续释放时停机。[基线代码](../experiments/q3_replay/order_baseline.py) · [正式规程第 2–3 页](../data/raw/C/Restocking_Tasks_and_Constraints/Problem_3_Requirements.pdf)
