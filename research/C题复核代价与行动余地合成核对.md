# C题复核代价与行动余地：合成核对

2026-11-20（本机日期核对为 CST）。基线提交 `71c4c34`。

**结论：同一时长分布、同一个完全揭示回执，仍可因剩余交期和可行动预算不同而有不同价值。** 固定动作时，信息本身不改善结算；允许改变顺序时，下面的极小合成例能严格提高期望按时权重，但会增加费用和相对直接执行的拖期，不能称为无条件的“净收益”。

本笔记只核对官方公开条件、手算和虚构样例。不读取或重跑验证/测试结果及既有9对实证，不拟合模型，不设计、选择或冻结参赛策略。两个例子只执行 S1 中一至两个现有作业，其余停止，**不是 S1 完整求解或有效性实验**；另补充一个预算边界。

AI 辅助记录：2026-11-20，OpenCode 中的 Sonus · Qoder · Remote magpie（provider `magpie`，model `remote-magpie/qoder/smodel`；模型具体发布日期未获提供）。用途为官方规则核对、合成反例构造、手算与既有引擎对账、文字整理。参赛模型、推导及论文采用须由队员独立审核；使用情况按[官方 AI 使用规定](https://www.nmmcm.org.cn/News/220.html)另行核验和披露。

## 1. 哪些有官方支持，哪些没有

### 1.1 核对依据

- [英文题面](<../problem/C/2026_“ShuWei Cup”C_Problem.pdf>)第3–5页：Q3任务、复核、映射、结算和证据边界。
- [Problem_3_Requirements.pdf](../data/raw/C/Restocking_Tasks_and_Constraints/Problem_3_Requirements.pdf)第1–3页，§1–4：公开条件、信息隔离、合法动作和共同指标。当前附件目录没有题面所称的 `tasks_and_evaluation.md`，本次核对的是这份官方PDF，不假设缺失文件内容。
- [共同条件](../data/raw/C/Restocking_Tasks_and_Constraints/common_conditions.json)，版本 `q3-20261117-v1`；[tasks.csv](../data/raw/C/Restocking_Tasks_and_Constraints/tasks.csv)；[service_zones.csv](../data/raw/C/Restocking_Tasks_and_Constraints/service_zones.csv)。PDF以本地 `pypdf` 提取文本核对，不仅依赖中文译文。

官方案例为 S1：8项、H=100、B=32、K=4；S2：12项、H=100、B=34、K=6；S3：16项、H=125、B=40、K=8。公开任务确实有不同释放时刻、交期、权重和前置关系，例如 S2_J09 必须等 S2_J02 完成。这些事实支持“合法后续动作和资源余量不同”，**不支持“某个前缀一定更准、某次复核一定有收益”**。

以下保留 S1 原任务表：

|简写|官方作业|区域|释放|交期|权重|前置|
|---|---|---|---:|---:|---:|---|
|A|S1_J01|Z4=(2,0)|0|35|3|无|
|B|S1_J02|Z3=(1,1)|0|45|1|无|

全体8项的权重和为16。仅执行 A 时，其余7项的未完成拖期贡献为395；执行 A、B 时，其余6项为340；全不执行为590。这些常数均由官方任务表按未完成作业取 C=H 计算，**不把被省略的作业移出指标分母**。

### 1.2 结算不能混淆的三件事

在时刻 t、当前位置到目标距离 D，预留 b，实际服务 p：

\[
s=t+D+0.5,\quad C=s+p,\quad T_{\rm available}=s+\max(p,b),\quad c_{\rm exec}=2+0.1b+0.2D.
\]

执行前只检查已披露信息及 b≥0.2、s+b≤H、预算足够；不能用隐藏 p 作接纳依据。接受即收费，不因早完成退费；早完成也不提前释放预留。这里所有执行均在 H 内完成。

- **信息**：免费累计源前缀0.2秒；一次付费复核返回后扩至0.6秒，第二次至1.0秒。原始前缀不含源标识、总时长、终点和后续样本。
- **费用**：每次复核收费1，执行费用另算。信息改变顺序后若走不同路线，执行费变化属于行动后果，不是“信息本身免费省钱”。
- **设备/时钟**：复核独占1秒情景时间，期间不能执行或等待；信息只在结束时返回。等待1秒免费、不改位置、不扩展前缀，但同样推迟下一项执行。源前缀的0.4秒增量不是额外服务0.4秒，也不会抵扣 p。

### 1.3 唯一的虚构不确定性与回执

两例都设 A 的源时长 d=1.5或19.5秒，各概率1/2，名义映射 p=d+0.5，故 p_A=2或20秒。B 的 p_B=2秒为合成先验中的确定值；其他作业不执行。**这些时长、概率及其与回执的关系全是人为假设，没有读取源索引或原始轨迹来支持它们。** 满足 d≥1.2 只是与官方长度下限相容，不代表真实抽样池中有这样的记录或概率。

为避免让回执直接携带官方禁止的 `duration` 字段，脚本虚构一个允许的数值通道：0.2秒内两种世界的 `head_pose.position` 完全相同；源时刻0.4秒起，其 x 分量为0表示短、1表示长。这个“坐标与总时长完美对应”的关系也是虚构且事先给定的，**不是真实手/头位姿的解释，不是源前缀匹配或训练结论**。复核后只按这个返回值分支，不读取隐藏时长、源标识或随机种子。

在该假设下，A 的熵一直是1 bit（复核前），方差81秒²；回执 Y 完全揭示两种状态，条件互信息为1 bit、后验熵为0。不同起始时刻/预算只改变排程条件，不改变此分布或信息量。真实的“同样扩展0.4源秒”**并不等于**同样获得1 bit。

## 2. 反例一：动作不变，完全信息也不能改善结算

A 固定预留 b=20，执行后 STOP，不因回执更改作业、顺序或预留。比较设备仍在 Z0 的两个决策时刻：宽松 t=0、紧 t=12。t=12 在引擎中由开局共同 WAIT 12到达，不修改官方交期；两世界在等待期间没有新披露。

三条动作链：

- **D：直接执行** A，费用4.4。
- **W：WAIT 1，再执行同一 A**，费用仍4.4；这是等延迟、不披露的归因对照，不是付费复核的全部反事实。
- **R：REVIEW A，返回后执行同一 A**，费用5.4；回执虽完美，后续动作不变。

D 的 C=t+4.5或t+22.5；W、R各晚1秒。b=20使 D 的设备释放恒为t+22.5，W/R恒为t+23.5；短世界预留空闲18秒，长世界0。

|决策时刻|动作|A的完成时刻（短 / 长）|期望按时权重（仅A）|总费用|设备释放时刻|
|---|---|---|---:|---:|---:|
|0|D|4.5 / 22.5|3|4.4|22.5|
|0|W|5.5 / 23.5|3|4.4|23.5|
|0|R|5.5 / 23.5|3|5.4|23.5|
|12|D|16.5 / 34.5|3|4.4|34.5|
|12|W|17.5 / 35.5|1.5|4.4|35.5|
|12|R|17.5 / 35.5|1.5|5.4|35.5|

归因：D→W 只有1秒延迟；W→R增加费用1并披露信息，但在固定动作下结算不因信息改善。宽松时无服务损失，紧时长世界错过35秒交期；两者收到的都是同一个1 bit。

全部共同指标的压缩核对：各链 `weighted_completion_rate=3/16`，期望 `reserved_idle_s=9`，超预留/截尾/违规均0，`valid_protocol=true`。宽松三链及紧D的 `weighted_on_time_rate=3/16`、`weighted_tardiness_s=395`；紧W/R分别为 `1.5/16`、395.75。`elapsed_s`等于上表设备释放时刻，费用见表，R复核1次，其余0次。准确知道短作业已结束，**不允许撤销已经承诺的18秒空闲预留**。

此例仅证明信息未用于改变动作时不能凭熵下降产生服务收益，不证明所有允许调节 b 的方案都无信息价值。

## 3. 反例二：能改变顺序时，紧交期下存在有限目标的正收益

A、B均固定 b=0.2，保留官方移动与切换；只改变两者顺序，完成两项后 STOP。比较 t=0 与 t=29（后者由共同开局 WAIT 29到达）。不是人为改交期，也不是推荐先空等29秒。设 g=√2。

### 3.1 四层归因与一个必要的直接对手

- **D_AB**：立即 A→B；**D_BA**：立即 B→A，防止只挑弱的直接对手。
- **W_AB**：WAIT 1，A→B。不给新信息、不扣复核费。
- **M_AB**：REVIEW A，返回后仍固定 A→B，忽略回执。这是在真实延迟及费用下不使用信息的对照；引擎仍正常披露，M不伪造一种官方未定义的“扣费但不返回”动作。
- **R_choose**：REVIEW A；宽松时无论回执都 A→B；紧时短→A→B，长→B→A。动作分支仅在回执返回后触发。

D→W分离延迟；W→M分离复核费用（这两者后续固定相同）；M→R在相同复核费用和时钟下核对利用回执改顺序的作用；R→D才是购买复核的完整比较。若预算不足，W/M合法行动集本就不同，不能把W称为严格“纯信息价值”。

### 3.2 紧时刻 t=29 的逐世界手算

|动作/回执|C_A|C_B|按时权重 A+B|总费用|
|---|---:|---:|---:|---:|
|D_AB，短|33.5|36+g = 37.414214|4|4.44+0.2g|
|D_AB，长|51.5|54+g = 55.414214|0|同上|
|D_BA，短|34+2g = 36.828427|31.5+g = 32.914214|1|4.04+0.4g|
|D_BA，长|52+2g = 54.828427|31.5+g = 32.914214|1|同上|
|R_choose，短，AB|34.5|37+g = 38.414214|4|5.44+0.2g|
|R_choose，长，BA|53+2g = 55.828427|32.5+g = 33.914214|1|5.04+0.4g|

W_AB、M_AB 的完成时刻都为 D_AB 相应行加1秒；M再多付1，故无需另抄时间线。每次执行的移动费和0.5秒切换均包含在式子中。预留0.2导致 p>b，设备释放等于完成时刻；不是在完成前改变已执行作业，也不是把信息当作服务进度。

短世界中 AB 保住高权重A；长世界中 A无论如何已不能按时，BA可保住B。若先执行A再利用执行反馈，长世界反馈到达时B交期已经过去，不能补救。

- **紧时可严格证明的正收益**：在只考虑这两个作业、顺序AB/BA及固定 b 的小动作集内，直接AB的期望按时权重为2，直接BA为1；随机混合也不超过2。R为2.5，增益0.5，即全S1分母下按时率提高0.03125。即使允许只做其中一项或停止，也不超过直接AB的期望2。这里没有声称优于官方全部8项上的最优无复核调度。
- **信息使用的条件价值**：紧时R相对M，同样付费复核后按时权重多0.5、拖期少0.714466；长世界改走BA，使期望执行费少0.058579、结束早0.292893。这些路线收益来自回执驱动的动作改变。
- **购买复核的总代价仍存在**：紧时R相对直接AB，期望费用多0.941421、已用时间多0.707107、加权拖期多1.285534。不能据按时率改善声称所有指标改善。
- **宽松时同一信息无按时收益**：不买信息也能让A、B都按时；按时权重上界4已达到。直接BA还比AB便宜、快，因此不能将“不必要地先选AB再靠回执换BA”的路线改善冒充必须购买信息的理由。

若仅为解释“净”的含义，设外部给定效用为期望按时权重减 λ×费用，不将它推荐为参赛目标：紧时R相对D_AB的差为 `0.5 − λ×0.941421`，仅当 λ<0.531112（权重/成本单位）时为正。若再惩罚已用时间或拖期，还应扣除相应的0.707107、1.285534乘以各自价格。不给偏好和量纲，就没有唯一的“净价值”。

## 4. 同一回执在预算边界上可能没有行动余地

复核本身可付，不等于复核后可执行。当前位置Z0，A取 b=0.2 的执行报价为2.42；若一个**明确虚构的资源边界**只剩2.42，则直接执行可行，复核后只剩1.42，低于任意执行最低费用2.02，回执无论多准也不能再执行。K有余量、时间充足仍不能解决这个问题。

为检验算术，脚本另用 S1 任务表和同一规则，**显式将预算改为2.42并标记非S1官方案例**，时刻29、其余动作同前。这不是从真实S1历史推导出的可达剩余预算，不是官方B=32的实验结果。

|动作|期望完成率|期望按时率|期望加权拖期|费用|已用时间|复核数|期望超预留|
|---|---:|---:|---:|---:|---:|---:|---:|
|直接A，b=0.2|3/16|1.5/16|419.75|2.42|42.5|0|10.8|
|等待1秒再同样执行|3/16|1.5/16|421.25|2.42|43.5|0|10.8|
|付费复核后合法STOP|0|0|590|1|30|1|0|

三行空闲/截尾/违规均0且规程有效。最后一行是未执行，不是“执行但被截尾”；**没有故意下达超预算执行指令来制造失败**。费用较低只是因为没有服务，不能称作节约成功。相比之下，B=32的合成紧例允许复核后两种分支执行；保证两分支均能执行所需总预算为至少 `5.44+0.2√2 = 5.722843`。两预算的信号和不确定性完全相同，差别是付费后合法动作集。

在同一延迟和剩余资源下，允许忽略信息时，“已获得信息后的最优决策价值”不会因信息本身下降；上述负向差异来自购买信息消耗资源/时间，而不是信息减少可选动作。这也解释了为什么需要M对照，不宜只做R减D。

## 5. 实际执行的核对与不能外推的结论

[合成核对脚本](../experiments/c_q3_review_slack_check.py)只读三个公开文件：`common_conditions.json`、`tasks.csv`、`service_zones.csv`；导入[既有引擎](../experiments/q3_replay/engine.py)，不调用真实数据适配器。隐藏时长只由离线引擎结算；合成分支只看返回数值。全部源样本在脚本内虚构。

```sh
python3 -B experiments/c_q3_review_slack_check.py
```

2026-11-20实际执行通过：19条极小动作链×短/长两个世界，共38条合成轨迹；每条11项共同指标，**418项手算—引擎数值核对通过**。另断言：返回前只见0.2秒；返回后才见0.6秒；复核1秒内无决策回调；复核收费1且位置不变；预算边界复核后不足最低执行费用。只输出终端，不新增数据结果文件，不运行现有测试套件、采样验证或9对实证。

这里的418只是算术断言数，38不是38个独立实证样本。手算公式与引擎的评分函数分别实现，但二者都按同一套规则，**通过不等于模型有效、全引擎无误或真实回执有1 bit信息**。

最终证据边界：

1. **已支持**：官方规则确有复核占用、收费、前缀隔离、不可提前释放预留、预算和交期约束；因此仅凭熵或相同前缀长度不能确定排程价值。
2. **仅在合成假设下支持**：完全回执可在有后续行动余地时改善某一服务目标，也可被延迟、费用及行动集限制抵消；正收益不是由信息量单独决定。
3. **本次未核查、不能主张**：真实前缀与剩余总时长的预测关系/校准、真实复核增益、任何参赛排序或阈值有效性。需要这些证据才能把合成条件用于真实回放，本文不提出或执行相应模型选择。
4. 本文故意只服务一至两项，完整分母下所有名义按时率均低于0.50，**不能充当成本/产能风险主目标的达标结果**，更不证明官方任务不可行。未完成仍计分，合成现象不代表机器人性能。
