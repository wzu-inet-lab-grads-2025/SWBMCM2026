# 2026“数维杯”C 题：无人超市补货作业的状态估计与决策优化

> 本文为所提供英文赛题的中文译文，不含解题方案。文件名、字段名、符号及参考文献信息按原文保留。原文图内文字以“图内文字”列出，便于在 Markdown 中完整阅读；原图也一并保留。

## 1 背景

机器视觉、物联网和电子支付在零售领域的应用日益广泛，将商品识别、便捷结算和数字化运营结合起来。无人零售在社区、商务园区和校园中具有发展潜力。其持续运营也依赖及时、可靠且成本可承受的补货服务。

补货涉及反复进行的商品整理、抓取、放置和搬运。货架边缘、操作人员的手部以及移动的补货车都可能遮挡视野，而运动速度和作业阶段会随任务及环境变化。图 1 展示了补货场景中可能出现的遮挡。系统必须评估现有信息的可靠性，决定何时再次观测，并在有限时间和资源下安排后续工作。

人类操作记录为研究这些问题提供了证据。观测质量是指手部位置、朝向等记录信息的完整性和可靠性；字段缺失、遮挡以及靠近图像边缘等情况都可提供相关证据。实际运动、观测质量和阶段转换能够支撑状态估计与作业规律模型，并进一步为补货决策提供依据。将这些规律应用于机器人时，需要解释手部状态与商品状态之间、人类与机器人作业时长之间的关系，以及这些关系的适用条件。

## 2 问题

### 问题 1：作业状态与观测可靠性建模

与补货相关的操作包括伸手、抓取、放置、搬运和整理。在不同环境、作业阶段及观测条件下，相似操作可能表现出不同的运动模式与信息质量。

读取并整理全部三组原始数据，检查时间对齐、坐标约定、重复记录和质量标记。“记录”指一次采集序列中的操作数据；“时间区间”指一条记录中的连续部分。根据字段完整性、时间连续性和观测质量，判断哪些记录及区间可用于模型拟合、误差评估、低质量观测分析，哪些应当排除，并说明理由和筛选标准。建立描述作业状态和观测可靠性变化的数学模型，研究不同任务、环境或阶段之间的差异。

### 问题 2：观测缺失期间的状态预测与重新观测

当手伸入货架深处时，其作业状态可能暂时变得难以观测。保持最后一次记录的状态可能引入误差，而频繁观测又会消耗资源。研究在没有新观测时，预测误差或不确定性如何增长，在有合理依据的容差范围内能够持续预测多长时间，以及何时应请求新的观测。

本问题要求在预测误差与观测支出之间进行权衡。沿用问题 1 中选定并定义的状态变量。建立适用于观测缺失时段的预测及不确定性更新模型，分析缺失持续时间、作业阶段和历史信息的影响，并确定请求时刻与等待安排。随着信息返回，更新评估。等待是指不再提出额外请求，或等待已请求的信息返回；利用已有信息进行预测仍可继续。可以在满足误差要求的条件下最小化观测成本和等待，也可以在给定资源下提高预测精度。请说明目标、容差及权衡。

在真实记录上开展人工遮蔽与回放实验：选择具有合格参考状态的区间，暂时隐藏选定时刻或通道的信息，仅使用当时可获得的信息进行预测，再以留出的记录进行评估，如图 3 所示。“观测缺失窗口”规定隐藏观测的开始与结束时刻。窗口、观测预算、每次请求成本和返回延迟均为事先固定的实验条件，所有对比方法共同遵守。决策内容是何时请求观测以及如何等待；预测误差、累计成本和等待时间是评价指标。实验应可复现。其实验结果不代表机器人的实际性能。

重新观测只能返回原始记录中实际存在的时刻和通道的信息，且在返回延迟结束前不得使用这些信息。与保持最后状态、简单运动预测或固定间隔观测等基线比较，报告误差、不确定性和观测支出。利用自然遮挡分析其发生、持续时间和恢复情况。对于没有独立参考的低质量区间，不得计算真实位置误差。解释人工遮蔽与自然遮挡的差异；不要求选择任意新的观测视角。实验约定见 `Data_Documentation/missing_observation_experiments.md`。

### 问题 3：不确定性下的补货作业调度

对于附件提供的补货相关作业，利用原始操作记录估计作业时长及其不确定性。在有限时间和成本下，确定优先执行哪些作业及其顺序、各作业预留的服务时长、付费信息复核和等待安排。评估完成情况、按时服务情况、成本及设备占用。

执行前，为每项作业预留一段设备服务时间。该预留服务时长是决策变量，而不是已知的实际发生时长。超时会推迟后续作业；若服务提前完成，预留时间中的剩余部分仍占用设备，并成为空闲时间。作业顺序、预留时长及是否付费复核已有信息，都会影响后续调度。

将前两个问题结合到调度模型中，并应用于所提供的任务案例 S1、S2 和 S3，无须另行构造任务清单。图 4 展示记录片段与情景作业之间的关系。一个工作单元对应一个带文本标注的区间，而不是一件商品。在 349 个区间中，持续时间至少为 1.2 秒的 343 个区间参与共同采样，其余区间仍保留在源索引中。三个案例分别包含 8、12、16 项作业，时间范围上限 H 分别为 100、100、125 秒，成本预算分别为 32、34、40，付费复核次数上限分别为 4、6、8。成本采用抽象单位。

`Restocking_Tasks_and_Constraints/tasks.csv` 列出了每项作业的释放时刻（最早可用时刻）、交期（期望完成时刻）、权重（相对重要性）、服务区域和前置作业（执行前必须已完成的作业）。作业可以在交期之后、但在 H 以内完成，此时记录拖期。H 到达时，整个试验终止。字段定义与示例见附件指南。

决策包括优先执行哪些作业及其顺序、每项作业预留的服务时长、是否及何时付费复核、等待多久，以及何时停止。图 5 展示这些关系。按时完成、拖期、累计成本、超时和预留空闲时间是评价指标。请自行选择研究重点和优化目标，论证权重与权衡，并对每种方法报告全部共同指标。

共同约束规定每项作业最多执行一次，且执行、复核和等待不得并行。须遵守释放时刻、前置关系、时间及成本限制。若原始标注时长为 d，则情景服务时长为 αd + β。名义映射取 α = 1、β = 0.5 秒。进行敏感性测试：保持 β = 0.5 秒，令 α = 0.75 或 1.5；保持 α = 1，令 β = 0 或 1 秒。从原始记录估计时长模型及其不确定性，并在留出记录上评估。

预留服务时长 b 必须至少为 0.2 秒。对于区域间距离 D，移动与切换耗时为 D + 0.5 秒，执行成本为 2 + 0.1b + 0.2D。执行前检查预算和预留时间区间。若实际情景服务时长为 p，开始时刻为 s，则完成时刻为 s + p，设备在 s + max(p, b) 时重新可用。若服务跨越时间上限 H，则终止试验，并将该作业计为未完成。按照附件规则核算全部动作及成本。

## 4 共同评价指标与比较

开放的优化目标用于体现研究重点，共同指标则用于核验结果。问题 1 应报告保留的记录数和时间戳数、数据划分、模型参数、状态误差或一致性、质量模型表现以及不确定性检查。指标应与状态定义相匹配，不得只汇总容易处理的样本。

问题 2 应报告预测误差、不同缺失持续时间下的表现、区间覆盖率或集合可靠性、观测次数和成本、等待时间及计算开销。对于代表性三维点，可使用下列平均距离误差。其他状态表示需要采用适当的指标和单位。

$$
E = \frac{1}{M}\sum_{k=1}^{M}\left\|\hat{x}_k-x_k^{\mathrm{ref}}\right\|_2.
$$

其中，M 为参与评估的时间戳数量，帽号表示预测，上标 ref 表示符合质量要求的留出记录参考值。该指标衡量预测与记录参考值之间的偏差，并不能据此确认三维商品定位精度。对于概率区间，应报告名义覆盖率、经验覆盖率和区间大小，而不是仅通过加宽区间来提高覆盖率。

问题 3 应将在留出记录上的时长模型或状态模型误差，与共同情景中的加权完成、加权按时完成、加权拖期、成本、复核次数、已用时间、观测到的超时、预留空闲时间、已执行但在时间上限处仍未完成的作业，以及不可行指令等指标分开报告。未完成作业仍应保留在服务指标的分母中，计算拖期时以 H 作为其完成时刻。保留发生规程违规的试验。完成的工作单元数不是商品件数；没有实体机器人实验，不得报告实际机器人成功率。

比较时使用相同的记录、作业、信息和资源，并分析状态模型、信息安排及作业顺序的贡献。按记录或环境汇总原始数据验证结果。对于问题 3，按任务案例汇总配对试验，报告差异与波动。说明自定义目标的量纲或尺度、权重及依据；不同队伍或偏好所定义的分数，不能直接按数值大小进行比较。
