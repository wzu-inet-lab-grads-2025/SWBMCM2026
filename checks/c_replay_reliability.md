保持原样；数值向量内藏字典/字符串、非有限数、质量叶中的任意对象在回调前
以 ValueError 失败关闭。不填补/插值，不改正常样本值及顺序。

输入污染回归直接记录实际回调，证明源引用/未来统计等额外键不渗入；干净、
污染版本的正常日志相等且源对象不变。未观察后缀不提前投影或泄露。

### `experiments/q3_replay/acceptance.py`

`verify_ledger` 不调用引擎报价、准入或评分函数，按公开规则独立检查：

- 预算、预约下界、计划时域、完成/设备可用 ≤H；费用按公开参数核算；
- 释放、前置作业、已完成不可再次处理、复核总量/单作业限额、动作限额；
- 终止后无回调，WAIT 必须正数，不能任意截断轨迹；
- 非法动作必须终止且无接受账本、无扣费；正确记录的拒绝可验算，但
  `valid_protocol` 仍为 false，不把它当合法策略运行；
- 回调 index/时间/公开条件稳定、预算与观察余额、完成反馈；
- 释放事件准确、仅已释放作业有观察、累计前缀按已返回 REVIEW 推进；
- 样本白名单、窗口内时间戳、已披露前缀不能删改；
- 源引用账本时刻只能是完成时刻或删失 H；全部 11 项指标核算。

样本结构投影与引擎共享；独立污染输入/输出断言防止只靠共享代码自证。
对预算/时域/披露已知错账均新增固定后的拒绝回归，没有“漏洞必须存在”断言。

## 手算、变形与故障覆盖

- EARLY 字面答案：C=5、设备可用=7.5、费用=3.7、预留闲置=2.5。
- CROSS：起点=96.5，H=100 未完成，费用=3.5、不退款，仅观察超时=0.5。

  占用期间释放、欧氏距离、同区换装、STOP 未完工迟延仍取 H。

## 待核与不保证

集成复核另用 S1 首个验证种子的固定动作脚本走了一次真实适配入口。导出日志与目录迁移后的基准逐字节一致，独立账本复算通过。含真实前缀的日志保存在本机 `runs/`。该复核覆盖一个既有样例，罕见编码及其他记录仍需相应证据。

1. **自洽但错误的完成时刻仍需独立真值**。仅凭公开日志无法区分 EARLY
   C=5 与协调改写后的 C=5.25；字面手算仍检出。类似地，首次披露的合法
   样本、源引用与作业是否真正对应、是否遗漏源样本，需外部可信源或见证。
2. 不认证初始公开条件是否与官方条件一致；它是此账本验算的可信起点。
   样本字典白名单不能识别允许数字/质量字符串中人为编码的未来信息。
3. 官方适配形状用合成对象验过，但没有读取真实源、重跑实证检查罕见值/形状。
   新入口对畸形许可字段失败关闭；新质量编码应先核实后显式扩展，不应整对象透传。
4. 有限合成回归不是全状态空间证明、代码变异覆盖率、正式成绩或真实设备证据。
   不验证原始数据标注/完整性、采样种子或跨文件真实对齐。
5. 仅见证当前阻塞回调；没有中点 API，不保证墙钟侧信道、真实送达时刻或恶意
   Python 的进程级隔离。不保证真值、见证和全部账本同时被改写后仍能检出。
