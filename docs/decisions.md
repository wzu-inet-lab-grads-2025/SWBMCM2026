# 建模口径决策

## 2026-11-20｜统一仰角边界口径

- **依据：**[B 题英文原题](../problem/B/2026_“ShuWei%20Cup”B_Problem.pdf)第 3 页规定云台仰角范围为 `[-10°, 80°]`，含两端点；同页另规定视线碰到楼体棱、面或顶点即遮挡。这两个边界的开闭不同。
- 2（1）按闭区间复核了草案的西、北两站取等构造，满足仰角、视线、净空和双车行驶时限，理论最小值可取。解析坐标是取等站位的依据。2（2）按同一闭区间生成候选站并重求优化和就近基线。[第二问复算说明](B_Question_2_Reproduction.md)
- 第四问的初始调度继承第二问（2）的仰角与视线口径。本次优化和基线均要求同一告警的两车驻站圆盘不重叠。路径与时序计算采用题面恒速及忽略避碰耗时的规则，并用全程两两车心距验收输出。第四问扰动改变路线时需对实际轨迹重新核对。

## 2026-11-20｜第四问实时接续、基线与评价窗

- 第二问（2）归档的 `optimized` 路径和时间轴不变。断联内车辆延续 t=0 队列，同步前失去搭档的正常车在指定站等待；已经开测的告警（含断联期间合法开始者）不改派。仅对重排的后缀做保守时间刻度，最终用连续轨迹重算真实开测。
- “保留原调度”同时报告不改原任务的追加版和严格冻结版。[命题人答疑](https://pd.qq.com/g/pd52619943/post/B_e4b7ff6a0ac20e001441152187121863520X60?subc=745397906)确认 `(5,30]` 是恢复时刻，停联历时为 `(0,25]` s。主评价用严格 `S<60`，同时独立记录 `S<=60` 对照；未全启的 `t_last=60`。五个故障车等概率，其他情景均值不当作真实期望。
- 固定原告警站位、复用第二问路由和 3 m 车距；可改旧站位只做敏感性，不归因于调度调整本身。本口径仅影响第四问，不重跑第二问。[审核与修订](B题第四问_方案审核与实现说明.md)
