# B 题讨论决定

## 二（2）以路程定义就近分配，以最早共同就绪作时间对照

团队确认用新增可行路程定义题目要求的“就近分配”。保留“两车新增可行路程之和最小”和“两车中较长的新增可行路程最小”两种距离规则。时间对照选取当前告警最早能共同开始观测的车对与站位，每辆车均须完成上一任务复位、到站并完成云台指向。

在相同候选站、可行路线和告警处理顺序下配对比较，记录并列规则。两类方案均用三个告警中最晚的观测开始时刻评分。[六种顺序的配对结果](q2-baseline.md)

初步比较已覆盖初始车位和独立 20 m 网格。在每组相同条件下，两种距离规则都选出相同分配。原地方案中，处理顺序为 T1、T2、T3 时，按编号打破距离并列得 22.332 s，按共同就绪时间打破并列得 10.969 s。后续比较需明确报告并列规则，保留零行驶可行上界作为验收数据。
