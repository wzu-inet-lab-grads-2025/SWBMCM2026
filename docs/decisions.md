# B 题讨论决定

## 二（2）保留两种距离规则进行配对比较

团队选择保留“两车新增可行路程之和最小”和“两车中较长的新增可行路程最小”。在相同候选站与路线、相同处理顺序和相同并列规则下比较全部六种告警顺序，用三个告警中最晚的观测开始时刻评分。主基线待证据比较后决定。[初轮结果](q2-baseline.md)

初步比较已覆盖初始车位和独立 20 m 网格。在每组相同条件下，两种距离规则都选出相同分配。原地方案中，处理顺序为 T1、T2、T3 时，按编号打破距离并列得 22.332 s，按共同就绪时间打破并列得 10.969 s。后续比较需明确报告并列规则，保留零行驶可行上界作为验收数据。
