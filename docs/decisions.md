# C 题队伍决定

## 2026-11-20 · 第一、二问共享腕点与首轮回访

**范围为首轮诊断。正式状态仍开放。** 队伍允许先用左右腕第 0 点的 XYZ 跑通回放，逐手预测、逐手计算三维距离误差。两手和各方法共用 50 个不重叠验证窗，按记录和环境报告。每次回访从一个已存在的源时刻取双腕 XYZ，合为一包计一次，延迟届满方可使用。队伍随后明确希望先理解关节轨迹和区间标注，再讨论代表点、坐标尺度与可比较样本池。旧结果保留其原有口径。[决策依赖图](C题决策依赖图.md)

首轮诊断采用每窗最多一次、每包费用 2、每窗预算 2、返回延迟 0.5 秒的示例条件。可请求的方法共用资源条件。先以保持最后可靠点给出不回访曲线。正式容差由队伍结合训练误差、坐标单位和应用需求确定，正式延迟范围参考训练敏感性。变更腕点、窗、预算或时钟口径后，须重跑对应的误差曲线和请求账本。[分层结果与复现](../research/C题双腕缺测时长与回访诊断.md)

## 2026-11-20 · 腕点误差的逐手尺度假设

队伍同意在腕点诊断中按记录、按手估计参考长度 `L`。用遮挡前可见且质量合格的历史，取同手腕点（0）至中指掌指关节（9）距离的中位数，在该窗内固定。并列报告厘米误差和 `误差/L`。若应用容差以厘米规定，超差按厘米判定。该假设适用于能从合格历史估计 `L` 的窗口。[尺度与覆盖核验](../research/C题关节映射与无量纲误差核验.md)

若后续研究指尖动作并拟跨人共用手型模板，先检验按 `L` 缩放后剩余的手指比例差异是否足以改变动作判断或预测误差。正式状态、主指标、容差以及拇指内部关节的解剖对应仍待确定。[手型与拇指核对](../research/C题拇指编号与操作员手型核对.md)

## 2026-11-21 · 第一轮收敛反馈

- **Q1/Q2 正式运动状态待定。** 队伍保留手腕位置、旋转、手指弯曲、握拳/手型及相对位置的讨论。既有双腕包仅用于已跑过的诊断。讨论每个候选时要说明它表达什么动作、怎样评分、历史和回执需包含什么信息。[候选量与同窗检查](../research/C题腕姿手型与相对位置候选核对.md)
- **Q2 暂定展示方式，正式目标开放。** 首轮并列展示误差、观测支出及等待。正式比较前根据应用选择给定预算提高精度，或给定有依据的容差节省费用与等待。说明选择依据，保留共同指标和权衡曲线。
- **Q3 暂定评价偏好，正式目标开放。** 既有试跑按加权按时完成率优先、加权拖期次之解读。队伍会根据案例需求、共同约束与拟研究的服务或成本问题确定正式目标及冲突时的选择规则。FCFS 与 EDD 已获认可为合适的排序基线。新增对照、正式策略、预留及复核仍待确定。

## 2026-11-21 · 多种手部表示与观测价值

- **认可按用途保留多种表示。** 世界系腕点和朝向、腕部局部指形、两手相对量分别服务于平移、旋转、张合与协同问题。哪些分量进入正式 Q1/Q2 状态、回访报价及容差仍开放。
- **认可研究观测的行动价值。** Q1 提供历史信息能解释哪些状态或质量事件的证据，Q2/Q3 研究付费信息在延迟、预算与剩余行动时间下的价值。队伍基本同意通过同实际支出对照检验熵规则，保留结合预测、恢复时间及决策后果的候选。混合规则的增益仍须验证。
- **认可增加调度对照的方向。** 优先补 WSPT，若正式目标重视交期再比较最小松弛时间。复核对照考虑零复核、付费使用、相同复核安排下付费但忽略三种情形。排序对照共用其他模块，这项取舍不冻结正式目标。

## 2026-11-21 · 第一项讨论的共识

队伍认可腕位、腕向、指形与双腕相对运动分别评分，指形在补货操作中应得到充分考虑。连续指形用于描述手部运动；若要声称出现了新的物体操作，还要核对物体和动作边界。正式评分主次及付费通道仍开放。后续以明确目标比较指形在腕部信息之外的增量。[指形的训练对照](../research/C题腕姿手型与相对位置候选核对.md)
