## 0. 审核结论与本次修订

原先提出的五种方法方向基本合理，但不能直接按“各自算出结果，然后取最优值”执行。审核后作以下修订：

1. **把五种方法定位为同一概率模型的不同求解/近似方法，而不是五个可以任意挑选结果的模型。** 一阶近似只作基准；精确几何数值积分作为主要结果；蒙特卡洛和 Sobol 用于独立验证。
2. **增加一维精确角度积分。** 由于 X、Y 定位误差独立且标准差相同，旋转坐标系后仍是各向同性二维正态分布。可以解析消去径向变量，将二维积分降为一维角度积分。这比单纯二维积分更高效，建议作为主方法。
3. **保留二维 Gauss–Hermite 求积作为独立确定性校验。** 它直接对原始二维高斯定位误差求期望，不依赖一维角度密度公式，可检查一维化简及实现是否正确。
4. **修正题面 Δψ 的定义歧义。** 题面先把 Δψ 描述为“指令方位角与真实方位角之差”，但又给出云台零位误差、控制误差，并要求比较三类误差源。严格按前一句，云台两项误差不会进入 Δψ；按实际系统测向精度理解，则应将其加入最终实际指向误差。必须同时计算两种口径，并在报告中明确主口径及理由。
5. **误差贡献不能只报方差占比。** 同时提供一阶方差贡献比例和逐项消融实验；前者便于解释，后者直接衡量每个误差源对达标概率的影响。
6. **数值方法的“最好”指精度、稳定性和可复现性最好，不是结果最乐观。** 不允许从多个结果中挑选最大的允许里程，也不允许对不一致结果简单平均。

建议主报告采用“最终实际指向误差（包含三类误差）”口径，因为它才能同时评价定位、云台零位和云台控制三类误差；另将“严格按题面字面定义的指令角误差”作为口径敏感性结果单独报告。若竞赛官方答疑对 Δψ 有明确解释，以官方解释为准并更新主口径。

## 2. 统一符号、坐标系与误差定义

### 2.1 坐标系

将真实车辆位置设为原点，并将真实车辆至目标的水平视线旋转到正 X 轴：

- 真实车辆位置：`P=(0,0)`；
- 目标位置：`T=(D,0)`，其中 `D=40 m`；
- 车辆估计位置：`P_hat=(δx,δy)`；
- 定位误差：`P_hat-P=(δx,δy)`。

由于题目规定两个方向误差独立、同方差正态，定位误差协方差为 `σ² I`，旋转坐标系不会改变其分布。因此可以把视线方向作为 X 轴，不损失题目给定的随机性信息。

### 2.2 定位误差分布

给定累计行驶距离 `s` 时：

`δx ~ N(0, σ_L(s)^2)`，`δy ~ N(0, σ_L(s)^2)`，且二者独立。

第一小问：

`σ_L(s) = 0.3 + 0.02s`（单位 m）。

第二小问：

`σ_L(s) = a + bs`，其中 `a ≥ 0`、`b ≥ 0`；`a` 的单位为 m，`b` 的单位为 m/m（数值上无量纲）。

### 2.3 定位误差引起的指令方位角偏差

车辆根据估计位置计算目标方向。目标相对估计车辆位置的向量为：

`T - P_hat = (D-δx, -δy)`。

因此，定位误差引起的指令角偏差为：

`α = atan2(-δy, D-δx)`。

`atan2` 先返回弧度，计算和报告时必须明确单位。实现中建议内部统一用弧度计算几何角，再在与云台误差合成前转换为度。

注意：沿视线方向的定位误差单独发生时不会在一阶上改变方位角；垂直视线方向的误差直接改变方位角。一阶近似为：

`α ≈ -δy / D`（弧度）。

这只是小误差近似，不能替代主模型。

### 2.4 云台误差

定义：

- `ε0 ~ N(0, 0.8²)` 度：云台零位偏置误差；
- `εc ~ N(0, 0.6²)` 度：云台控制误差。

两者独立，且与定位误差独立。若将二者视为同一水平角轴上的可加误差，则总云台误差：

`εg = ε0 + εc ~ N(0, σg²)`，

`σg = sqrt(0.8² + 0.6²) = 1.0°`。

计算总达标概率时可以合并为 `εg`；进行三类误差贡献分析时必须保留 `ε0`、`εc` 两个独立分量，不能把它们永久合并。

### 2.5 必须同时实现的两种 Δψ 口径

**口径 A：严格按题面前半句的“指令角偏差”解释。**

`Δψ_cmd = wrap180(α)`。

此口径只包含车辆定位误差，不包含云台零位和控制误差。它与题面“指令方位角相对于真实方位角的偏差”的字面定义一致，但无法用该指标比较云台两项误差对最终测向误差的影响。

**口径 B：实际执行后的最终指向误差（建议作为工程主口径）。**

`Δψ_act = wrap180(α + ε0 + εc)`。

此口径把车辆定位、云台零位和云台控制三类误差全部纳入实际相机指向偏差，能够满足题目后续比较三类误差源的工程意图。

角度回绕函数统一定义为：

`wrap180(x) = ((x + 180) mod 360) - 180`。

所有角度均以度传入该函数，输出范围为 `[-180°,180°)`。

**报告要求：** 两种口径都计算并列出结果差异；主结果明确采用口径 B 的理由；不要把口径 A 和 B 的结果混在同一张表中。若后续取得官方答疑，按官方口径更新。

## 3. 统一概率模型

### 3.1 主指标

定义最终实际指向的达标概率：

`R_act(σ) = P(|Δψ_act| ≤ 5°)`。

其中 `σ` 表示当前定位标准差，目标距离 `D=40 m` 固定，云台合成标准差 `σg=1°` 固定。

指令角口径另定义：

`R_cmd(σ) = P(|Δψ_cmd| ≤ 5°)`。

### 3.2 条件概率降维

给定定位误差所产生的指令角偏差 `α`，云台合成误差 `εg~N(0,1²)`。最终误差满足角度回绕后的条件达标概率为：

`G(α) = Σ[k∈Z] { Φ((5-α+360k)/σg) - Φ((-5-α+360k)/σg) }`。

这里 `α` 和 `σg` 均以度为单位，`Φ` 是标准正态分布函数。数值实现不必无限求和；对本题 `σg=1°`，从 `k=-1,0,1` 开始，并增加项数，直到概率变化低于设定容差。不得直接忽略角度回绕而不说明。

于是：

`R_act(σ) = E_{δx,δy}[G(atan2(-δy,D-δx) × 180/π)]`。

这就是所有数值方法必须共同计算的目标。

### 3.3 将二维积分精确化为一维角度积分（建议主方法）

令估计位置到目标的向量为：

`X = D-δx`，`Y=-δy`。

则 `X~N(D,σ²)`、`Y~N(0,σ²)`，且独立。令 `α=atan2(Y,X)`，其角度概率密度为二维各向同性正态向量的投影正态角度密度。

对 `α∈[-π,π)`，定义 `μ(α)=D cos α`，角度密度为：

`f_α(α;D,σ) = exp(-D²/(2σ²))/(2π) + [D cos α/(sqrt(2π)σ)] × exp[-D² sin²α/(2σ²)] × Φ(D cos α/σ)`。

这里 `α` 使用弧度，`f_α` 是每弧度的概率密度；`D`、`σ` 使用相同长度单位。

因此主口径概率可写为一维积分：

`R_act(σ) = ∫[-π,π] f_α(α;D,σ) × G(α×180/π) dα`。

严格指令角口径为：

`R_cmd(σ) = ∫[-5π/180, 5π/180] f_α(α;D,σ) dα`。

这一步是精确的概率降维，不是小角度近似。它利用了题目给定的两个坐标方向同方差、独立正态这一条件。实现时必须做密度归一化检查：

`∫[-π,π] f_α(α;D,σ)dα ≈ 1`。

数值实现要注意 `cos α<0` 时公式中两项可能发生浮点抵消。应使用稳定的正态尾概率/`erfcx` 等实现，或将极小尾部单独稳定处理；若密度出现明显负值或归一化不通过，不能继续报告结果。对本题临界区域，概率质量集中在 α=0 附近，可将积分区间分段并在 0 附近增加积分控制点。

## 4. 五种方法的并行实现要求

五种方法都要实现，但其角色不同。所有方法必须共用同一参数配置、误差定义和角度回绕规则。

### 方法 1：一阶泰勒近似＋正态解析基准

用途：提供可解释的解析近似和量级检查，不作为最终主结果。

一阶定位角误差：

`σ_pos,deg ≈ (180/π) × σ/D`。

若采用最终实际指向口径，合成标准差近似为：

`σ_total,deg ≈ sqrt(σ_pos,deg² + 0.8² + 0.6²)`。

忽略极小的角度回绕尾部时：

`R_1(σ) ≈ 2Φ(5/σ_total,deg) - 1`。

求解 `R_1(σ)=0.95` 得到近似临界标准差。必须报告它与精确几何主方法的差异，并解释小角度近似条件。不得把一阶结果当作精确结果。

### 方法 2：二维 Gauss–Hermite 高斯求积

用途：对原始二维正态定位误差直接求期望，作为独立确定性校验。

令 `Zx,Zy` 独立服从标准正态，`δx=σZx`、`δy=σZy`。计算：

`R_act(σ)=E[G(atan2(-σZy,D-σZx)×180/π)]`。

使用二维乘积 Gauss–Hermite 求积。建议测试阶数：`n=16,24,32,48,64,96,128`，记录每个阶数的概率、与前一阶的差值和耗时。若采用 `roots_hermitenorm`，节点对应标准正态权函数，二维权重归一化分母为 `2π`；若采用其他 Hermite 约定，必须核对权重变换，防止漏乘 `sqrt(2)` 或归一化错误。

### 方法 3：一维投影正态角度密度＋自适应数值积分

用途：**主要求解方法**。

直接实现第 3.3 节的 `f_α` 和 `R_act` 一维积分。建议使用自适应 Gauss–Kronrod/`scipy.integrate.quad`，设置严格绝对和相对误差容限，并对 `[-π,π]` 分段积分。对 `R_cmd` 同样使用一维积分。

必须输出：积分估计值、积分器误差估计、密度归一化误差、分段结果。改变积分容差或分段方式后，结果应保持稳定。

### 方法 4：直接蒙特卡洛模拟

用途：从随机试验角度独立验证概率模型。

每次模拟独立生成：

- `δx,δy ~ N(0,σ²)`；
- `ε0 ~ N(0,0.8²)` 度；
- `εc ~ N(0,0.6²)` 度。

按原始 `atan2` 几何计算 `α`，再计算 `Δψ_act=wrap180(α+ε0+εc)`，统计 `|Δψ_act|≤5°` 的频率。指令角口径另统计 `|wrap180(α)|≤5°`。

建议先运行 `N=10^6`，使用 Wilson 或 Clopper–Pearson 区间报告达标概率置信区间；使用至少 5 个独立随机种子检查重复性。若临界附近置信区间过宽，再增加样本量。**蒙特卡洛不负责给出高精度临界距离**：在真实概率约 0.95 时，百万次模拟的概率区间仍有可见宽度，不能据此声称临界里程精确到 0.01m。

为了有效验证，建议在确定性主结果的 `s_crit-0.5m` 和 `s_crit+0.5m` 等临界点两侧位置运行模拟，而不是只在恰好 95% 的根上判断通过/不通过。根据实际概率差和置信区间决定是否增加 N。

### 方法 5：Scrambled Sobol 准蒙特卡洛

用途：用低差异序列对概率积分进行高效交叉验证。

建议使用二维 Sobol 序列生成 `U1,U2`，通过标准正态逆 CDF 转换为 `Zx,Zy`，再计算定位角 `α`，并对云台误差使用条件概率 `G(α)`。这样相当于先对云台随机误差做条件积分（Rao–Blackwell 化），降低维度和方差：

`R_act(σ) ≈ mean[G(atan2(-σZy,D-σZx)×180/π)]`。

使用 scrambled Sobol，样本数按 `2^m` 增长，例如 `m=12,14,16,18,20`；每个规模使用至少 8 个独立 scramble/seed，报告各组均值、组间标准差和收敛趋势。转换前对极端 0/1 值做数值裁剪，防止逆 CDF 返回无穷。

可选：另实现 3/4 维 Sobol 直接抽样云台误差，作为额外对照；但主 QMC 结果建议使用二维条件期望版本。

## 5. 临界标准差、最大行驶距离与 a-b 可行域

### 5.1 先求临界定位标准差

主口径定义：

`σ_crit = sup{σ ≥ 0 : R_act(σ) ≥ 0.95}`。

数值上先扫描合理区间，检查 `R_act(σ)` 随 `σ` 增大是否单调下降；再自动寻找满足 `R_act(σ_low)>0.95`、`R_act(σ_high)<0.95` 的括区，使用 Brent 求根或二分法求解：

`R_act(σ_crit)-0.95=0`。

不能只凭一个求根器返回值就宣称是最大值。需要提供概率曲线和单调性检查。若扫描发现非单调，停止使用单根假设，检查概率定义、角度回绕和数值误差。

指令角口径另求 `σ_crit,cmd`，不可与主口径混用。

### 5.2 第一小问：最大允许累计行驶距离

题目给定：

`σ_L(s)=0.3+0.02s`。

在主口径单调性成立时：

`s_max=(σ_crit-0.3)/0.02`。

若计算得到 `σ_crit<0.3`，说明初始状态就不满足要求，应报告无非负可行行驶距离，而不是输出负距离。指令角口径也单独计算对应结果供敏感性比较。

### 5.3 第二小问：80m 时 a、b 的约束

`σ_L(80)=a+80b`。

若可靠性随定位标准差单调下降，则：

`a+80b ≤ σ_crit`，同时 `a≥0,b≥0`。

这是第一象限内直线下方的参数可行域，不是唯一一组 a、b。必须报告边界截距：

- `b=0` 时 `a≤σ_crit`；
- `a=0` 时 `b≤σ_crit/80`；
- 边界为 `a+80b=σ_crit`。

绘制 a-b 可行域图，标注单位和可行/不可行区域。另给出指令角口径下的敏感性可行域，但正文主结果采用与 R2 一致的口径。

## 6. 三类误差源贡献分析

不能把“误差标准差大小”直接当作“贡献大小”。必须先统一为角度单位，并区分近似方差贡献和精确可靠性影响。

### 6.1 一阶方差贡献比例（解释性指标）

定位误差的一阶角度标准差：

`σ_pos,deg ≈ (180/π) × σ/D`。

三类方差近似为：

- 定位贡献：`V_pos=(σ_pos,deg)²`；
- 云台零位贡献：`V_zero=0.8²`；
- 云台控制贡献：`V_control=0.6²`。

总方差近似：

`V_total=V_pos+V_zero+V_control`。

每类方差贡献率：

`C_i=V_i/V_total`。

至少在以下工况报告：`s=0`、主口径 `s=s_max`、`s=80m`。明确说明这是小角度线性化下的方差贡献比例，不是精确非线性模型的可加贡献。

### 6.2 精确概率消融（工程影响指标）

在相同累计行驶距离和相同其他条件下，分别计算：

- `R_all`：三类误差全部保留；
- `R_no_loc`：定位误差设为 0，只保留两种云台误差；
- `R_no_zero`：零位误差设为 0，保留定位和控制误差；
- `R_no_control`：控制误差设为 0，保留定位和零位误差。

定义每类误差的消融改善量：

`ΔR_i = R_without_i - R_all`。

`ΔR_i` 越大，说明在该工况下消除该误差源带来的可靠性改善越明显。该指标不是可加分解，不能把三个 `ΔR_i` 相加后解释为总贡献。建议同时报告 `ΔR_i` 和方差贡献率，避免单一指标误导。

### 6.3 部署建议必须由结果推出

例如：若短里程时云台零位误差占比高，应强调零位标定；接近允许里程时定位误差占比快速上升，应强调定位校准、累计行驶距离管理或途中重新定位。不得在没有计算支持时先写结论再反向挑数据。

## 7. 方法比较、择优规则与数值验收

### 7.1 方法角色

| 方法 | 是否近似 | 角色 | 是否用于最终主结果 |
|---|---|---|---|
| 一阶泰勒＋正态解析 | 是 | 解析基准、量级检查 | 否 |
| 二维 Gauss–Hermite | 对积分作数值求积 | 独立确定性校验 | 可作为交叉验证 |
| 一维投影正态密度＋自适应积分 | 几何概率模型精确，积分数值近似 | 主方法 | **是，优先采用** |
| 直接蒙特卡洛 | 抽样估计 | 独立统计验证 | 否，不用于高精度根值 |
| Sobol 准蒙特卡洛 | 数值积分估计 | 高效交叉验证 | 否，除非验证后主方法更适合且误差有界 |

### 7.2 推荐验收标准（项目自定，不是竞赛官方阈值）

- 一维积分：改变积分容差、区间分段后，`R` 变化建议小于 `1e-8`；积分器误差估计需同时保存。
- 二维 Gauss–Hermite：增加阶数后，临界区域概率稳定；与一维主方法的 `R` 差异建议小于 `1e-7`，若达不到需继续提高阶数或排查实现。
- 临界标准差：不同高精度确定性方法求出的 `σ_crit` 差异建议小于 `1e-6 m`；如计算条件不允许，至少要使换算后的 `s_max` 差异远小于论文报告精度，并说明实际误差界。
- 临界距离：检查 `s_max-0.01m`、`s_max`、`s_max+0.01m` 的确定性概率，确认边界两侧关系；概率计算容差必须明显小于边界两侧的概率差。
- Monte Carlo：报告样本量、随机种子、Wilson/Clopper–Pearson 置信区间。若置信区间不能区分临界点两侧，应增加样本量或把验证点移到临界点外侧更合理的位置；不能强行宣称通过。
- Sobol：报告每个 `2^m` 样本量、独立 scramble 次数、均值和组间波动，检查收敛趋势。
- 单调性：在覆盖临界点的足够宽 σ 网格上检查 `R(σ)` 是否下降；并提供概率-σ 或概率-s 曲线。

### 7.3 正确的“择优”规则

1. 先检查各方法是否实现了同一个 Δψ 口径、相同单位、相同角度回绕和相同参数。
2. 一维积分和二维 Gauss–Hermite 作为确定性结果相互核对。
3. Monte Carlo、Sobol 用置信区间/重复 scramble 波动核对确定性结果。
4. 一阶近似用于解释误差大小和近似偏差，不参与“谁给出的里程最大谁胜出”的竞选。
5. 如果方法间差异超过验收阈值，必须定位原因（公式、角度单位、Hermite 权重、积分尾部、随机误差、wrap 处理），不能取平均或选最有利结果。
6. 最终采用**满足数值误差要求且可独立复核的原始几何模型结果**。若一维积分和二维求积一致，优先报告一维积分结果，并将二维求积作为验证；如果一维密度实现不稳定，则以经收敛验证的二维求积为主，并说明原因。
