# 4. 几何模型的具体实现

## 4.1 T1 坐标转换

输入：

\[ (`\theta`{=tex},R,H)=(30\^`\circ`{=tex},40,45) \]

\[ O=(50,50) \]

计算：

\[ x_T=50+R`\cos`{=tex}(`\theta`{=tex}) \]

\[ y_T=50+R`\sin`{=tex}(`\theta`{=tex}) \]

\[ z_T=H \]

注意：Python 的 `math.sin/cos` 输入为弧度，必须先 `radians(theta)`。

参考断言：

``` python
assert abs(x_T - 84.6410161514) < 1e-9
assert abs(y_T - 70.0) < 1e-9
assert abs(z_T - 45.0) < 1e-12
```

相机位置：

\[ C=(x,y,2) \]

垂直高度差：

\[ `\Delta `{=tex}h=45-2=43 \]

## 4.2 车辆与场地边界

车辆中心必须满足：

\[ 1.5`\le `{=tex}x`\le98.5`{=tex} \]

\[ 1.5`\le `{=tex}y`\le98.5`{=tex} \]

相切允许。按闭边界比较。

``` python
inside_field = (
    x >= rho
    and x <= field_width - rho
    and y >= rho
    and y <= field_height - rho
)
```

## 4.3 车辆与建筑物

对建筑底面矩形 (R_i=\[x_i^-,x_i^+\]`\times[y_i^-,y_i^+]`{=tex})，计算：

\[ d_x=`\max`{=tex}(x_i\^- - x, 0, x-x_i\^+) \]

\[ d_y=`\max`{=tex}(y_i\^- - y, 0, y-y_i\^+) \]

\[ d_i=`\sqrt{d_x^2+d_y^2}`{=tex} \]

车辆圆盘不侵入建筑物：

\[ d_i`\ge1.5`{=tex} \]

Python 参考实现：

``` python
def point_rect_distance(x, y, b):
    dx = max(b.x_min - x, 0.0, x - b.x_max)
    dy = max(b.y_min - y, 0.0, y - b.y_max)
    return math.hypot(dx, dy)


def check_vehicle_geometry(x, y, cfg):
    rho = cfg.vehicle_radius

    if not (
        rho <= x <= cfg.field_width - rho
        and rho <= y <= cfg.field_height - rho
    ):
        return False

    for b in cfg.buildings:
        # 圆角距离临界时复核平方距离；恰好相切允许。
        if disk_enters_rectangle(x, y, rho, b, cfg):
            return False

    return True
```

不得把车辆圆盘简化为中心点，也不得把矩形障碍简单膨胀成四角仍为直角的外接矩形。点到原始矩形的最短距离公式已经正确表示圆盘与矩形的碰撞条件。

## 4.4 云台仰角

水平距离：

\[ r(x,y)=`\sqrt{(x-x_T)^2+(y-y_T)^2}`{=tex} \]

仰角：

\[ `\alpha`{=tex}(x,y)=
`\operatorname{atan2}`{=tex}(43,r(x,y))`\cdot`{=tex}`\frac{180}{\pi}`{=tex}
\]

仰角约束：

\[ -10^`\circ`{=tex}`\le`{=tex}`\alpha`{=tex}`\le80`{=tex}^`\circ`{=tex}
\]

本题 (`\Delta `{=tex}h=43\>0)，所以仰角始终为正，实际起作用的是 80°
上界。

等价距离条件：

\[ r(x,y)`\ge `{=tex}r_0,`\qquad`{=tex}
r_0=`\frac{43}{\tan80^\circ}`{=tex} \]

参考值：

\[ `\boxed{r_0=7.582060170464\text{ m}}`{=tex} \]

代码应同时保留 `elevation_deg` 和
`horizontal_distance`，最终结果不能只存 bool。

对当前高于相机的 T1，标量和网格的可行性都用同一水平距离下界。`atan2` 提供输出角度与独立复核。目标正下方的水平距离为 0、仰角为 90°。最优圆和见证点按未舍入公式构造，浮点表示需满足同一距离判定，保留圆周参数用于复现。

# 5. LOS：线段与三维长方体相交检测

这是最需要认真实现和测试的几何函数。建议自行实现 Slab /
参数区间法，不要用二维阴影代替三维检测。

## 5.1 线段参数方程

\[ C=(x,y,2),`\quad `{=tex}T=(x_T,y_T,45) \]

\[ L(t)=C+t(T-C),`\quad `{=tex}t`\in[0,1]`{=tex}\]

必须检测有限线段，不能检测无限延长直线。

## 5.2 建筑物 AABB

每栋建筑：

\[ \[x\_{`\min`{=tex}},x\_{`\max`{=tex}}\]
`\times[y_{\min},y_{\max}]`{=tex}`\times[0,H]`{=tex}\]

## 5.3 Slab 算法的可执行伪代码

对 x、y、z 三个轴分别计算线段进入和离开该轴区间的参数范围，最后取交集。

``` python
def segment_aabb_intersects(p0, p1, box, eps_pos, eps_t):
    """
    返回线段 [p0,p1] 是否与闭 AABB 相交。
    闭 AABB 语义：面、棱、顶点接触均算相交。
    """
    t_enter = 0.0
    t_exit = 1.0

    for axis in (0, 1, 2):
        p = p0[axis]
        d = p1[axis] - p0[axis]
        lo = box.lower[axis]
        hi = box.upper[axis]

        # 线段在该轴方向平行
        if d == 0:
            # 平行且位于盒子闭区间外：不可能相交
            if p < lo or p > hi:
                return False
            # 平行且位于闭区间内：该轴不进一步收缩 t 区间
            continue

        if abs(d) <= eps_pos:
            return intersects_closed_box_by_faces(p0, p1, box)

        t1 = (lo - p) / d
        t2 = (hi - p) / d

        t_near = min(t1, t2)
        t_far = max(t1, t2)

        t_enter = max(t_enter, t_near)
        t_exit = min(t_exit, t_far)

        # 明确分离时可提前返回，临界交集留给精确复核。
        if t_enter > t_exit + eps_t:
            return False

    # t_enter/t_exit 已与 [0,1] 求交
    if abs(t_enter - t_exit) <= eps_t:
        return intersects_closed_box_by_faces(p0, p1, box)
    return t_enter <= t_exit
```

实现时要确保
`box.lower=(x_min,y_min,0)`、`box.upper=(x_max,y_max,height)`。

临界复核可用有理数比较输入端点与闭盒各面。先检查端点是否在盒内，再以各面交点参数验证接触是否发生在有限线段和闭盒范围内。这个判据也用于独立复核最终站位。

## 5.4 LOS 汇总

``` python
def check_los(x, y, cfg):
    camera = (x, y, cfg.camera_height)
    target = cfg.target_xyz
    blocked_by = []

    for b in cfg.buildings:
        box = building_to_aabb(b)
        if segment_aabb_intersects(
            camera, target, box, EPS_POS, EPS_T
        ):
            blocked_by.append(b.id)

    return (len(blocked_by) == 0), blocked_by
```

必须使用闭盒相交：与建筑物任何面、边、顶点接触都属于遮挡。

## 5.5 必须覆盖的 LOS 特殊情况

-   穿过盒子内部；
-   与盒子一个面相切；
-   与棱边接触；
-   与顶点接触；
-   与盒子平行且在盒子外；
-   与盒子平行且位于盒子闭范围内；
-   线段在建筑物上方通过；
-   线段水平投影经过建筑物，但高度始终高于建筑物；
-   线段端点接触建筑物；
-   某一坐标方向分量为零；
-   某一坐标方向分量很小但非零，且各轴的进入与离开次序决定有无交集；
-   只有延长线穿过建筑。

若
`d == 0`，不得执行除法。不得因高度未参与检测而将二维投影重叠误判为遮挡。

# 6. 单站完整评估函数

实现一个统一入口，将三类约束组合起来。

``` python
def evaluate_station(x, y, cfg):
    vehicle_ok = check_vehicle_geometry(x, y, cfg)

    dx = x - cfg.target_xyz[0]
    dy = y - cfg.target_xyz[1]
    r = math.hypot(dx, dy)

    elevation = math.degrees(
        math.atan2(cfg.target_xyz[2] - cfg.camera_height, r)
    )
    gimbal_ok = gimbal_feasible_at_distance(r, cfg)

    los_clear, blocked_by = check_los(x, y, cfg)

    feasible = vehicle_ok and gimbal_ok and los_clear

    clearance_min, _ = compute_clearance(x, y, cfg)

    return StationCheck(
        x=x,
        y=y,
        horizontal_distance=r,
        elevation_deg=elevation,
        vehicle_ok=vehicle_ok,
        gimbal_ok=gimbal_ok,
        los_clear=los_clear,
        blocked_by=blocked_by,
        feasible=feasible,
        clearance_min=clearance_min,
    )
```

-   网格在同一批点生成三个独立掩码。顺序筛选计数使用掩码的累积交集；
-   `feasible` 必须严格等于三个子约束的逻辑 AND；
-   `clearance` 的定义见第 9 节。

## 7.1 网格定义

推荐使用**单元中心采样**，不要把网格节点和网格单元混淆。

当网格间距 (h) 能整除 100 时：

\[ x_i=(i+0.5)h,`\quad`{=tex} y_j=(j+0.5)h \]

\[ i,j=0,`\ldots`{=tex},`\frac{100}{h}`{=tex}-1 \]

分辨率：

-   调试：1.0 m；
-   常规论文区域图：0.25 m；
-   收敛性对比：0.5 m、0.25 m、0.125 m。

0.25 m 网格是 400×400，共 160,000 个候选单元；0.125 m 网格是 800×800，共
640,000 个候选单元。

本问接受能整除场地两边的正间距，按整数单元数生成中心。等面积单元均使用面积 $h^2$。

## 7.2 网格计算的精确流程

每个网格点分别计算：

\[ M_v(i,j),`\quad `{=tex}M_g(i,j),`\quad `{=tex}M_l(i,j) \]

最终：

\[ M(i,j)=M_v(i,j)`\land `{=tex}M_g(i,j)`\land `{=tex}M_l(i,j) \]

**必须保存三个独立掩码和最终掩码。**

区域计算建议：

``` python
def build_observable_region(cfg, resolution):
    xs = np.arange(resolution / 2, cfg.field_width, resolution)
    ys = np.arange(resolution / 2, cfg.field_height, resolution)
    X, Y = np.meshgrid(xs, ys, indexing="xy")

    vehicle_mask = vectorized_vehicle_mask(X, Y, cfg)
    gimbal_mask = vectorized_gimbal_mask(X, Y, cfg)

    # LOS 需要逐建筑物做三维线段检测。
    # 对所有网格点分块运行，保留独立 LOS mask。
    los_clear_mask = vectorized_or_chunked_los_mask(X, Y, cfg)

    observable_mask = (
        vehicle_mask & gimbal_mask & los_clear_mask
    )

    area = int(observable_mask.sum()) * resolution**2

    return RegionResult(...)
```

### 性能要求

-   点到矩形距离和仰角约束应尽量 NumPy 向量化；
-   LOS 对网格点分块处理，避免一次性创建过大的中间数组；
-   LOS 可对每栋建筑物进行向量化 Slab 运算；
-   如果当前项目的网格规模较小，简单循环也可接受，但必须记录耗时；
-   不得为了性能降低几何判定精度或忽略建筑物。

## 7.3 两种统计口径必须分开

输出以下两组统计：

**独立约束通过数量：**

-   通过车辆几何约束的网格数；
-   通过云台仰角约束的网格数；
-   LOS 独立无遮挡的网格数。

**顺序筛选数量：**

-   全部网格；
-   车辆筛选后剩余；
-   再经云台筛选后剩余；
-   再经 LOS 筛选后剩余；
-   最终可观测网格数。

不能将独立约束通过数量直接相加，声称是各约束排除的点数，因为约束之间可能重叠。

# 8. 主目标优化：解析下界和全局最优证明

## 8.1 优化模型

\[
`\max`{=tex}\_{(x,y)`\in`{=tex}`\mathcal `{=tex}F}Q(x,y),`\qquad `{=tex}Q=1/r
\]

等价于：

\[ `\min`{=tex}\_{(x,y)`\in`{=tex}`\mathcal `{=tex}F} r(x,y) \]

其中：

\[ r(x,y)=`\sqrt{(x-x_T)^2+(y-y_T)^2}`{=tex} \]

## 8.2 解析理论下界

相机到目标的垂直高度差：

\[ `\Delta `{=tex}h=43 \]

仰角上界 80°：

\[ `\arctan`{=tex}(43/r)`\le80`{=tex}\^`\circ`{=tex} \]

因此：

\[ r`\ge `{=tex}r_0=`\frac{43}{\tan80^\circ}`{=tex} \]

参考值：

\[ `\boxed{r_0=7.582060170464\text{ m}}`{=tex} \]

所以任意可行解都满足：

\[ Q`\le`{=tex}`\frac{1}{r_0}`{=tex} \]

\[ `\boxed{Q_{\max}\le0.131890274875\text{ m}^{-1}}`{=tex} \]

## 8.3 可行见证点

取目标水平投影正东方向：

\[ P_w=(x_T+r_0,y_T) \]

参考值：

\[ `\boxed{P_w=(92.223076321842,\ 70.000000000000)}`{=tex} \]

验证用未舍入的构造公式，表中坐标是显示近似。程序对该点运行完整独立检查。

-   车辆未越界；
-   车辆不侵入 B1--B5；
-   仰角等于 80°；
-   LOS 与 B1--B5 均不相交。

若通过，则该点达到理论下界：

\[ r(P_w)=r_0 \]

于是：

\[ `\boxed{r^*=r_0,\quad Q^*=1/r_0}`{=tex} \]

主目标全局最优性证明完成。

**不要把见证点直接当成最终站点。**
它只负责证明主目标最优值可达。最终站点还要经过破同分规则选择。

# 9. 理论最优圆周、可行弧段和破同分算法

## 9.1 最优圆参数化

所有主目标最优点必须满足：

\[ (x-x_T)^2+(y-y_T)^2=r_0\^2 \]

令：

\[ x(`\varphi`{=tex})=x_T+r_0`\cos`{=tex}`\varphi`{=tex} \]

\[ y(`\varphi`{=tex})=y_T+r_0`\sin`{=tex}`\varphi`{=tex} \]

\[ `\varphi`{=tex}``\in[0,2\pi)
\]

原二维连续优化由此转化为一维角度可行性和一维次级优化。

## 9.2 找出全部可行角度区间

用题设几何覆盖整个最优圆。先验证全圆在场界内、只有 B2 的车辆扩张区域可能与圆相交。本题两个车辆可行性边界分别来自 B2 的北侧与东侧，按北侧和东侧相切方程计算端点，并检查接触点落在对应边段。用圆周在各象限的坐标变化核验端点之间的侵入状态，端点本身按车体相切可行计入。独立验证 B2 的 LOS 遮挡角段及其与车辆排除角段的包含关系，并记录几何条件。若任何覆盖条件未通过，报告无法认证全部角域。

以 0.01° 与 0.005° 全圆扫描、二分细化作为交叉检查，按 $10^{-8}$° 复核解析端点。扫描结果一致是复核证据。连续覆盖来自几何论证。采用 `[0°,360°)` 输出，以两段表示跨 0° 的弧，0° 计入，360° 对应同一点。

## 9.3 本题最优圆周的回归检查值

按上述官方参数，预计主目标最优圆周的可行角度集合为：

\[
\boxed{
\varphi\in
[236.89604685^\circ,360^\circ)
\cup
[0^\circ,160.74787333^\circ]
}
\]

边界的几何来源是 B2 周围车辆圆盘的排除边界：

- 一端对应车辆圆盘与 B2 东侧边界相切；
- 另一端对应车辆圆盘与 B2 北侧边界相切。

LOS 独立遮挡区间预计位于约：

\[
[169.9474^\circ,221.9272^\circ]``{=tex}\]

该 LOS
遮挡区间落在车辆本身已经不可行的角度区间内，因此不会进一步缩小本题最优圆周的最终可行弧段。

这些角度是**回归检查值**。实现 AI
必须从代码计算，不得直接写入程序作为答案。

## 9.4 次级优化目标：最大最小安全间距

定义车辆外缘到场地边界的净空：

\[ c\_{`\mathrm{field}`{=tex}}= `\min`{=tex}{
x-`\rho`{=tex}, W-`\rho`{=tex}-x, y-`\rho`{=tex}, H-`\rho`{=tex}-y } \]

车辆外缘到建筑物的净空：

\[ c_i=d_i(P)-`\rho`{=tex} \]

总体安全间距：

\[ `\boxed{
c(P)=\min\{c_{\mathrm{field}},c_1,\ldots,c_5\}
}`{=tex} \]

在所有主目标最优可行点中：

\[ `\boxed{
\max_{\varphi\in\Phi_{\mathrm{feasible}}}
c(x(\varphi),y(\varphi))
}`{=tex} \]

这是严格的字典序优化：先达到主目标
(r=r_0)，再最大化安全间距。不得为了增加安全间距而把站点移出最优圆。

## 9.5 次级优化必须做全局一维搜索

(c(`\varphi`{=tex}))
是多个距离函数的最小值，可能存在折点，不保证全局单峰。禁止只从一个初始点运行普通局部优化。

推荐采用以下可复现方法：

**阶段 A：全弧采样**

-   对全部可行弧段按 0.01° 采样；
-   计算每个角度的总安全间距及各分项；
-   识别所有局部峰值、端点和活跃约束切换候选点。

**阶段 B：局部精化**

-   对每个局部峰值邻域分别做有界一维优化；
-   对可能成为最小值瓶颈的两项安全间距，检查它们的交点；
-   比较所有候选点及所有可行区间端点；
-   不得只保留第一次优化返回的结果。

**阶段 C：全局上界复核（验收项）**

由于 (c(P)) 是到闭集合距离函数的最小值，沿半径 (r_0) 的圆周参数化后是
Lipschitz 连续函数，其关于角度的 Lipschitz 常数可取：

\[ L\_`\varphi`{=tex}=r_0 \]

这里的角度统一用弧度。若用度，常数为 $r_0\pi/180$。对经 §9.2 核对的可行角度区间 $[a,b]$，取中点 $m$，则

\[ `\max`{=tex}\_{`\varphi`{=tex}`\in[a,b]`{=tex}}c(`\varphi`{=tex})
`\le `{=tex}c(m)+r_0`\frac{b-a}{2}`{=tex} \]

可使用确定性 branch-and-bound：

1.  把每个可行角度区间放入最大上界优先队列；
2.  计算区间中点的 (c(m))；
3.  以上式作为区间最大值上界；
4.  若上界不超过当前最好值加 `EPS_CLEARANCE`，剪枝；
5.  否则二分该区间，继续计算；
6.  直到所有剩余区间上界与当前最好值之差不超过 `EPS_CLEARANCE`。

报告分支数、评价次数、全域上界和最终选中点的净空差。验收要求上界与最终选点的差不超过 `EPS_CLEARANCE`，并记录用于抵消浮点误差的余量。局部精化和参考数值用于提供候选或对照。

本题可另用东场界和 B2 东北角收紧上界。以两项净空相等的上半圆点的横坐标为分割。右侧由东场界净空控制，左侧下半圆由 B2 东侧净空控制，左侧上半圆到东北角的距离平方是凸函数，最大值取于两端。记录这个解析上界以及分支定界的上界，用于相互复核。

## 9.6 本题次级优化回归值

预计全局最大最小安全间距解为：

\[ `\boxed{
\varphi^*=56.503855631^\circ
}`{=tex} \]

\[ `\boxed{
P^*=(88.825410107,\ 76.322854075)
}`{=tex} \]

\[ `\boxed{
c(P^*)=9.674589893\text{ m}
}`{=tex} \]

该点的两个最紧约束预计为：

-   车辆外缘到场地东侧边界的净空；
-   车辆外缘到 B2 东北角的净空。

两者相等：

\[ 98.5-x\^\*=9.674589893 \]

\[ `\sqrt{(x^*-79)^2+(y^*-71)^2}`{=tex}-1.5 =9.674589893 \]

另一个需要保留的局部峰值回归检查点约为：

\[ `\varphi`{=tex}`\approx309.855434`{=tex}\^`\circ`{=tex},`\quad`{=tex}
P`\approx`{=tex}(89.5,64.179526) \]

其最小安全间距约为 9.0 m，低于全局候选值 9.67459 m。

最终结果允许有数值误差，但应满足：

-   \(r\) 与 (r_0) 的误差小于 (10\^{-7}) m；
-   仰角与 80° 的误差小于 (10\^{-7}) degree；
-   最小安全间距与参考值误差小于 (10\^{-5}) m；
-   x、y 坐标与参考点误差小于 (10\^{-4}) m。

如果不满足，先检查公式、参数、角度区间、车辆相切规则、LOS
接触规则和优化实现。不得为了通过验收而硬编码参考答案。

## 9.7 最终确定性破同分

先报告完整的主目标最优解集，再给代表站点和最终推荐点。最优解集由 §9.1 的参数式和 §9.2 的可行角域共同定义，是跨过 $0^\circ$ 的连续圆弧。代表点表包括 B2 两个可行相切端点和弧内示例，不能用有限个示例代替完整解集。

1.  同一理论圆周按主目标并列处理，核验距离下界与可行性。
2.  在主目标最优弧上选最小车辆净空最大的点。如此可增加车体到场界及各栋建筑的停放余量，不牺牲观测质量。
3.  净空差在浮点舍入余量内时按 x 坐标升序，再按 y 坐标升序。检查最终选中的点仍满足全局误差界。

`EPS_CLEARANCE` 是净空择优的全局误差界验收阈值。`tied_candidates` 记录净空在舍入余量内相同的有限求解候选数，不是连续主目标最优解集的大小。

不要把车辆初始位置、车辆行驶距离或 30 s
到达时间加入第一问的主破同分目标。
