### 1.3 单点约束和三维视线

1. 车辆中心位于 `[1.5,98.5]²`。点到每个建筑平面矩形的距离至少为 1.5 m。行驶段到每个建筑矩形的最小欧氏距离也至少为 1.5 m。按建筑“不得进入内部”的表述，车辆几何边界取闭集。用于计算的保守多边形近似见下节。
2. 令 `dx=tx-sx, dy=ty-sy`，用 `atan2(H-2, hypot(dx,dy))` 得仰角。检查 `-10 <= pitch_deg < 80`，禁止放宽严格上界。对本题的正高度差，可另外用 `r > (H-2)/tan(80°)` 复核临界点。
3. 三维视线从 `(sx,sy,2)` 到 `(tx,ty,H)`。用 Slab 算法将初始参数区间 `[0,1]` 依次与 x、y、z 各轴投影落入建筑闭区间时的参数范围求交。轴方向增量为零且坐标在轴区间之外时，当前建筑无交。最终参数区间非空，即使只有一点，也判遮挡。视线测试使用原建筑长方体。
4. `yaw_deg = degrees(atan2(dy,dx))`，位于 `[-180,180]`。转向和复位时长都等于 `max(abs(yaw_deg),abs(pitch_deg))/30`。用全精度计算可行性和时序，输出时才格式化。

### 1.4 路径子程序与可核验精度

对 2（2），主实现用**绕圆盘膨胀建筑的多边形可见性图**。实际圆角膨胀障碍是矩形与半径 1.5 m 圆盘的 Minkowski 和。用外切正多边形近似圆盘，并记录细分数 $n$。构造步骤如下。

1. 确定 $n=16,32,64$ 中的当前值，且 $n$ 为 4 的倍数。生成半径为 $1.5/\cos(\pi/n)$、顶点方位为 $(2k+1)\pi/n$ 的外切正 $n$ 边形。对每栋建筑，将四个矩形角与所有正多边形顶点逐对相加并取凸包。得到覆盖真膨胀障碍的外近似。圆盘近似的最大径向超出量为 $1.5(\sec(\pi/n)-1)$ m。
2. 将障碍顶点及场地内缩边界角点作为固定图节点。两节点连边条件为线段位于内缩场地内且与所有近似障碍的**内部**无交。沿近似障碍边界行驶允许。检查当前算例的近似障碍均在内缩场地内且互不交叠。如果换数据后发生交叠，先合并并裁剪边界再建图。
3. 固定图用 Dijkstra 建距离表和前驱表。每个查询端点预先保存它可直达的固定图节点及距离。查询时比较直连和经固定图的最短路径。经固定图的距离为 `min(d(p,u)+D_graph[u,v]+d(v,q))`，恢复获胜的两个接入点及路径。处在真自由空间但落入近似障碍内部的候选点，在当前离散模型中标作不可用，细化图后可重新纳入。
4. 路径表只预存行驶距离。保存端点接入信息和固定图前驱，最终对入选的路段恢复完整折线。任何输出路径必须用 `segment_drivable` 对每段独立重查，再重新求和长度。真几何检查可用线段与矩形相交或线段到矩形四边的最小欧氏距离，不使用对角线的端点采样替代整段检查。
5. 固定起终点、可见性图和障碍分辨率时，返回值是该保守多边形场地的最短路径长度。图离散带来的路径误差用 $n=32,64$ 实测对比。此误差与候选布站网格的误差分别报告。2（1）的解析构造采用经验证的直线路段，欧氏距离已达到该起终点最短路的下界。

## 2. 小问（1）双站误差模型和 T2 的结果

### 2.1 方位误差传播

设 $q=(x,y)$ 是目标水平投影，$p_i$ 是站点，$r_i=\lVert q-p_i\rVert$，$\alpha_i=\operatorname{atan2}(y-p_{iy},x-p_{ix})$。测量值是 $\hat\alpha_i=\alpha_i+\varepsilon_i$，其中 $\varepsilon_i\sim N(0,\sigma^2)$，两个角度误差相互独立，标准差 $\sigma=\pi/180$ rad。方位对目标坐标的雅可比矩阵第 $i$ 行是

$$
J_i=\frac{1}{r_i}[-\sin\alpha_i,\ \cos\alpha_i].
$$

对非退化双站交会在名义点处线性化，$J\Delta q\approx\varepsilon$，因此一阶协方差和精度指标为

$$
\Sigma_{\mathrm{lin}}=\sigma^2 J^{-1}J^{-\mathsf T},
\qquad E_{\mathrm{lin}}=\sqrt{\operatorname{tr}(\Sigma_{\mathrm{lin}})}
= \frac{\sigma\sqrt{r_1^2+r_2^2}}{|\sin\gamma|}.
$$

平方后的指标是线性化零均值位置误差的二维均方径向偏差，开方后以米表示。基线长度 $B=\lVert p_1-p_2\rVert$ 满足 $B^2=r_1^2+r_2^2-2r_1r_2\cos\gamma$。实现时从单位视线向量 $u_i=(q-p_i)/r_i$ 取 $s=|u_1\times u_2|$、$c=u_1\cdot u_2$，用 `atan2(s,c)` 得到 $[0,\pi]$ 内的交会角。用 $s$ 直接求 RMSE。需要协方差时用线性方程求解或 SVD。

### 2.2 利用题目几何给出连续下确界

T2 的 $H=35$ m，仰角严格小于 $80^\circ$，所以任一可行站都有

$$
r_i>r_0=\frac{33}{\tan 80^\circ}=5.8187903634\text{ m}.
$$

因 $|\sin\gamma|\le1$，所有可行组合都满足 $E_{\mathrm{lin}}>\sqrt2\sigma r_0$。构造 $r=r_0+\epsilon$ 且 $\epsilon>0$，将 V1 分配到 T2 的正西站 $p_W=(x_T-r,y_T)$，V3 到正北站 $p_N=(x_T,y_T+r)$。二者到 T2 的距离同为 $r$，交会角恰为 $90^\circ$，因此 $E_{\mathrm{lin}}(\epsilon)=\sqrt2\sigma(r_0+\epsilon)$。

实现时在 $\epsilon=0$ 的极限位置核对其他约束的**严格余量**，从而证明所有充分小的正 $\epsilon$ 都可行。

- 两个站点均在场地内缩边界内部。两条观测线进入 B3 的高度分别约 29.165 m、15.151 m，高过 B3 的 12 m 屋顶，此后视线继续抬高。两条视线均与其他建筑错开。
- V1 初始点至西站、V3 初始点至北站的直线均与所有建筑保持大于 1.5 m 的平面间距。极限直达行驶时间分别约 19.771 s 和 2.745 s，低于 30 s。两段路线距最近建筑的最小平面间距分别约 3.486332 m 和 2.318790 m。程序须对所有建筑逐栋计算最小间距，可将这一核验作为回归测试。
- 极限处唯一达到禁止边界的是 $80^\circ$ 仰角。由上述严格余量和连续性，构造从可行侧逼近下界。

由此得出**可行连续域的一阶 RMSE 下确界为 0.1436233579 m，严格仰角约束使其无法取到**。同一精度方案可能有多组车辆可实现。题目未要求以到达时间为次目标，直接报告这组已验证的车辆与路线即可。

### 2.3 程序入口及可复算的报告行

`solve_q21(radial_offset_m=0.01)` 依次执行下列操作。

1. 根据原始告警参数计算 T2 与 $r_0$，按上一节构造两个站点。配置中的 `radial_offset_m` 是给出有限坐标的构造参数，需为正，存入结果元数据。
2. 使用公共几何模块逐点验证，检查 V1 和 V3 的直达线段。如果换场景、改偏移或按给定小数位舍入后失效，返回失败原因并保留全精度结果，或显式选取另一个经验证的构造参数。官方实例的主结果以全精度有效坐标为准。
3. 计算 `B, gamma, r1, r2, RMSE`，分别输出两车路线、距离和时间。记录绝对差 $E_{\mathrm{lin}}-\inf E_{\mathrm{lin}}=\sqrt2\sigma\epsilon$。
4. 记录实际用于输出的站点坐标精度，重新验证序列化后的坐标与路径。论文中的站点数字应精确到复算后仍通过严格约束。

核心计算可直接实现为以下 Python 函数。其输出仍须通过第 1 节的几何判定。

```python
from math import atan2, cos, degrees, dist, hypot, radians, sin, sqrt, tan


def nominal_t2_pair(radial_offset_m: float = 0.01):
    if radial_offset_m <= 0:
        raise ValueError("radial_offset_m must be positive")
    x = 50.0 + 45.0 * cos(radians(150.0))
    y = 50.0 + 45.0 * sin(radians(150.0))
    lower_radius = 33.0 / tan(radians(80.0))
    radius = lower_radius + radial_offset_m
    if radius <= lower_radius:
        raise ValueError("offset is below floating-point resolution")
    sites = {"V1": (x - radius, y), "V3": (x, y + radius)}
    return (x, y, 35.0), sites, radians(1.0) * sqrt(2.0) * lower_radius


def pair_metrics(site_a, site_b, target):
    ax, ay = target[0] - site_a[0], target[1] - site_a[1]
    bx, by = target[0] - site_b[0], target[1] - site_b[1]
    r1, r2 = hypot(ax, ay), hypot(bx, by)
    if min(r1, r2) <= 0.0:
        raise ValueError("bearing is undefined directly below target")
    ua, va = ax / r1, ay / r1
    ub, vb = bx / r2, by / r2
    cross = abs(ua * vb - va * ub)
    dot = ua * ub + va * vb
    angle = degrees(atan2(cross, dot))
    rmse = float("inf") if cross <= 1e-12 else radians(1) * hypot(r1, r2) / cross
    return {
        "baseline_m": dist(site_a, site_b),
        "angle_deg": angle,
        "r1_m": r1,
        "r2_m": r2,
        "rmse_m": rmse,
        "sin_gamma": cross,
    }
```

### 2.4 退化和验证实验

- **交会退化。** $\det J=\sin(\alpha_2-\alpha_1)/(r_1r_2)$。交会角接近 0° 或 180° 时最小奇异值趋零，两条近共线视线主要约束其法向上的位置，沿视线方向的坐标约束很弱。一阶误差随 $1/|\sin\gamma|$ 放大。代码将秩亏组合判为无有效交会，避免用伪逆返回看似很小的误差。用于离散求解的浮点零判断可用 `abs(sin_gamma) <= 1e-12`，它只用于识别数值共线。若额外研究角度或精度门槛，单独记录阈值并做敏感性实验。
- **可见性边界。** LOS 相切与仰角恰为 80° 依题意不可行。合法的场地几何边界本身只会限制站位，不会改变雅可比公式。只要几何满足可观测性且 $J$ 满秩，公式仍可在该位置计算。对西站、北站用 $\epsilon=0.1,0.01,0.001$ m 报告仰角余量、最小路径间距、一阶指标与下确界差。可另对站点做小幅平面扰动，先报告是否仍可观测，再对合法位置报精度。
- **随机验证。** 固定种子，例如 42，使用至少 50,000 对独立 `Normal(0, pi/180)` 噪声。将带噪方向向量仍记为 $u_1,u_2$，求解 $[u_1,-u_2](\lambda_1,\lambda_2)^\mathsf T=p_2-p_1$，两射线正向相交时计算位置误差。记录退化样本数、负射线参数样本数、有效样本数、有效样本径向误差的中位数和 95% 分位数。近退化时，直接求交可能产生长尾，且有限样本 RMSE 会受极端值影响。若给出它，应标注“有效样本的有限样本 RMSE”并同时给出失败比例。在健康的 90° 站位对上比较线性化与直接交会的典型误差。在固定距离的合成角度实验中对比 `1°, 5°, 30°, 90°, 150°, 175°, 179°`，说明哪些区间线性化与直接交会差异大。

## 3. 小问（2）候选站点和时间递推

### 3.1 候选站点与查表数据

先使用间距 5 m 的二维网格，原点锚定在 $(1.5,1.5)$，另加入五辆车初始点、场地内缩边界上的规则采样点、通过检验的 2（1）站点，并去重。对每条告警各自通过 `station_valid` 过滤。之后用 2.5 m、1.25 m 两档逐步细化，保留上档已验证候选点。从 5 m 的完整候选集开始，定位可行方案后以它作为下一档 incumbent。

令 $S_j$ 是目标 $j$ 的候选集合，$n_j=|S_j|$。同一告警的两辆车必须不同，站点不同，交会几何非共线。车辆圆盘作为端点的单车约束按第 1 节执行。可在结果中标出同一告警两站距离是否小于 3 m。若另对同站区车辆空间重叠增加 `B>=3 m` 的约束，优化与基线须同步启用并作为单独口径报告。

| 表 | 形状 | 元素 |
|---|---|---|
| `D0[j]` | $5\times n_j$ | 初始车位至目标 $j$ 的站点路长 |
| `D[k,j]` | $n_k\times n_j$ | 前序告警 $k$ 的站点至后序告警 $j$ 的站点路长 |
| `g[j]` | $n_j$ | 指向 $j$ 的云台转向时长，同值作为复位时长 |
| `pair_ok[j]` | $n_j\times n_j$ | 是否可作为有效双站配对 |

两站之间的实际路径距离与告警编号无关，坐标重合就复用路长/路径结果。对称路长矩阵可转置复用。站点数较多时按块计算，距离与持续量用紧凑数组存储。初始方案可先用下文基线生成。遇到细网格超时，可以在 incumbent 站点周围做局部细化。默认在其各侧 5 m 的邻域加入下一档网格，和上档已验证点合并。此时记录实际候选集和全域粗网格结果。局部细化结果的证明范围为实际候选集。

### 3.2 固定一个方案后的精确递推

一项车次保存 `vehicle_id, target_id, site_id, predecessor_target_id`。每车首段 $d_{ij}=0$。若车 $i$ 在前序告警 $k$ 后执行告警 $j$，它的下一次出发时刻等于 $d_{ij}=S_k+5+g_k(p_{ik})$。令 $p_{\mathrm{from}}$ 为该车初始位置或前一站位置，则

$$
A_{ij}=d_{ij}+L(p_{\mathrm{from}},p_{ij})/3,\qquad
R_{ij}=A_{ij}+g_j(p_{ij}),\qquad
S_j=\max_{i\in\mathrm{pair}(j)}R_{ij}.
$$

共同观测窗是 $[S_j,S_j+5]$。每辆参与车等待量为 $S_j-R_{ij}$，复位窗为 $[S_j+5,S_j+5+g_j(p_{ij})]$。主目标 $C=\max_j S_j$。完整时间轴包括最后一次复位。最后一项完成后记录车辆待命，`next_departure_s=null`。

### 3.3 六种优先序足以覆盖所有可行的车辆顺序

每辆车的相邻任务在告警间建立一条有向边。共享车辆会使后序告警的启动至少比前序晚 5 秒，任何可行方案的依赖图都是 DAG。三个告警的 DAG 至少能拓扑排序为六种排列中的一个。因此，**枚举六种拓扑优先序，每种由优化器同时选择车辆和站位**，就能覆盖所有可行的离散分配与车辆任务次序。

例如优先序为 `T1,T2,T3` 时，若 T1、T2 没有共用车辆，二者都可从 $t=0$ 开始出车，也可以出现 T2 先开始观测。优先序只限制共用车辆的任务先后关系。模型中不添加 `S_T1 <= S_T2 <= S_T3`。

## 4. CP-SAT 实现与最优性口径

### 4.1 每个优先序的六个观测席位

每项告警用两个席位 $e=(j,a)$，$a\in\{0,1\}$。每席位建整数变量 `vehicle[e] ∈ [0,4]` 和 `site[e] ∈ [0,n_j-1]`。同一告警加 `vehicle[j,0] < vehicle[j,1]` 消去两席位的互换对称。用允许配对表或禁配表约束 `(site[j,0],site[j,1])`。稠密网格下优先用较小的那张表。

为每个席位计算其车辆真正的上一个席位。对所有位于更早告警的席位 $f$，定义：

- `same[f,e] ↔ (vehicle[f] == vehicle[e])`，用等式和不等式分别对布尔值的两侧加条件。
- `initial[e] ↔ AND(not same[f,e] for every earlier f)`。
- `previous[f,e] ↔ same[f,e] AND AND(not same[g,e] for tasks strictly between task(f) and task(e))`。

每个席位满足 `sum(previous[f,e]) + initial[e] == 1`。最早任务的两个席位固定为 `initial=true`。同告警两车不同，因此最近的较早告警中至多有一个符合条件的席位。布尔“当且仅当”两侧都要编码。

### 4.2 整数时间与查询索引

以 $\Delta=0.01$ s 为首轮 tick。**对车次总权重一次向上取整**，计算

$$
w^0_{ij}(b)=\left\lceil\frac{D^0_j[i,b]/3+g_j(b)}{\Delta}\right\rceil,
\qquad
w_{kj}(a,b)=\left\lceil\frac{5+g_k(a)+D_{kj}[a,b]/3+g_j(b)}{\Delta}\right\rceil.
$$

例如，初始查表索引 `index0 = n_j * vehicle[e] + site[e]`。从 $f=(k,a)$ 至 $e=(j,b)$ 的索引 `index_transition = n_j * site[f] + site[e]`。将权重表按行展开，并用 Element 约束得到初始或转场权重。先为索引声明整数变量，再加等式连接。查表无条件建立。对不可达表项使用大于可行上界的持续量，并只在其分支被选中时使该计划不可行。查表变量的域覆盖表内所有值，启动和准备变量的域可用上界收紧。

对所有席位和每个可能的前驱：

```text
if initial[e]:
    ready[e] = w0[e]
if previous[f,e]:
    ready[e] = start[target(f)] + transition_weight[f,e]
start[j] = Max(ready[j,0], ready[j,1])
C = Max(start[T1], start[T2], start[T3])
minimize C
```

用条件等式和 MaxEquality 表达这些关系。对每个优先序建一个模型。$t=0$ 时首任务出车，车辆复用的发车时刻由上一条告警的同步观测和本车复位确定。可用基线计划的**整数重放**最大启动时刻作全局上界，模型目标限制采用 `C <= upper_ticks`，仍保留并列解。若尚无可行上界，令时间域上限为三倍最大有限整数车次权重，并将不可达权重设得更大。对刚好在浮点整数倍附近的时间，验收时核对实际舍入误差与 tick 公差。

基线贪心可用数组外和生成两车距离和，并以配对掩码过滤。基线建立上界后，再用下述松弛界减少站点表规模。对每个告警和车辆，求该车从初始点到其任一可用站点的最早准备耗时，放宽配对和资源竞争。每个告警的下界可取这五个耗时的第二小值，整体再取三条告警中的最大值。它也是复用调度的有效下界，因为首段到最终站的最短路不会长于经其他任务绕行的同车行驶路径，且观测与复位只增加时间。对单个席位的“车辆、站点”组合也可做安全剪枝。若从该车初始点直达该站再转向的浮点耗时已大于当前整数上界乘以 tick，该组合不可能出现在任何能匹配上界的计划中。先去除无人可用的站点，再生成剩余的转场权重表。

### 4.3 解码、回放与最优值证明

1. 对每个优先序记录状态、整数可行值、求解器下界、候选数、tick、运行时间、随机种子。恢复每席位的车号和站点，沿优先序生成各车真实任务序列。先用整数权重重放验证 CP-SAT 的开始时刻，再用浮点原始路长、云台时间和路线重新回放。
2. 对同一路线和站点，整数目标 $C_\Delta\Delta$ 不小于浮点回放的 $C$。任一关键依赖链最多经过三条这样的权重边，二者差至多 $3\Delta$。如果六序的离散整数最优值为 $Z_\Delta$ ticks，则同一候选集、同一路径距离口径下的浮点最优值下界为 $\max(0,\Delta Z_\Delta-3\Delta)$。
3. 若部分模型超时，用各优先序的已证整数下界取**最小**后再换算浮点下界。没有返回可用下界的模型可用第 4.2 节的放宽界。若模型含 `C <= upper_ticks` 且已证明不可行，则该序的整数最优值大于该上界。保留全部有解模型中的最佳浮点回放方案，并把基线方案也纳入 incumbent 比较，给出上界、下界和差距。最终可声明的范围分别为“候选集内整数最优”“候选集内浮点差距上界”或“当前最优已知方案”。加密网格和路径多边形只能检验稳定性，不能据此宣称连续空间全局最优。
4. 为控制内存，按优先序复用预计算数组并逐模型释放求解对象。报告 5 m、2.5 m 和实际完成的更细档。若解在正式输出时采用更精细的路径，基线和优化方案须用同一距离口径复跑，原证明值与重新回放值分别报告。

## 5. 就近分配基线与对照

采用**实际避障路长和最短的双车贪心**。优化与基线使用相同候选站集合、路径精度、合法配对表、云台规则和浮点回放。对六种告警优先处理顺序各运行一次，步骤如下。

1. 所有车辆状态初始化为 `(initial_position, free_at=0)`。顺序扫描告警，枚举两辆不同的车与一个合法站点对。任何有后续可用时刻的车均可参与此次枚举，准备时间从其 `free_at` 起算。
2. 主排序键为两车从当前地点到各自站点的**避障路长之和**。按当前告警的最早联合启动时刻、车号和站号依次打破并列。两车到站并完成指向后共同启动，状态更新为各自站点与各自复位结束时刻。未选车辆状态保持原值。
3. 选择六次中 `C` 最小的可行方案作为基线，保存每个顺序的结果。优先处理顺序表示贪心承诺的顺序，未共享车辆的告警仍可并行。若某顺序无可行配对，记录失败告警及原因。
4. 比较同一回放口径下的 `C_greedy - C_opt` 和 `(C_greedy - C_opt) / C_greedy`，分母为零时比例记为空。逐条对照两方案在哪个告警被哪辆车卡住。沿决定最晚启动的前驱链，列出上一告警何时启动、5 秒观测、本车复位、接续行驶、转向和等另一车的影响。比较总路长、总等待可辅助解释，系统总量可能与关键链上的改变量方向不同。若最晚启动相同，如实报告并指出两套车辆路线或等待的区别。
5. 需要定位差异来源时，在同一候选集固定**基线车辆配对和每车顺序**，仅重新优化站点并回放。该值与基线的差量反映在固定任务结构下可以通过换站获得的改进。与全联合解的剩余差量反映释放车辆与任务顺序后的效果，记录各阶段的求解状态。

## 6. 回放参考伪代码与结果文件

实现一套统一的浮点回放，优化和基线均调用。根据每车任务序列生成 DAG，再拓扑处理。使用下列逻辑作为独立验收口径。

```text
for target in topological_order:
    for vehicle, station in assignment[target]:
        previous = previous_task_of(vehicle, target)
        origin = initial_position[vehicle] if previous is None else site[vehicle, previous]
        depart = 0 if previous is None else reset_end[vehicle, previous]
        route = shortest_route(origin, station)
        arrive = depart + route.length_m / 3
        turn_duration = gimbal(station, target).turn_s
        ready[vehicle, target] = arrive + turn_duration
        save(depart, route, arrive, ready)

    start[target] = max(ready[vehicle, target] for vehicle in pair[target])
    end[target] = start[target] + 5

    for vehicle, station in assignment[target]:
        wait = start[target] - ready[vehicle, target]
        reset_end[vehicle, target] = end[target] + gimbal(station, target).reset_s
        save(wait, start[target], end[target], reset_end[vehicle, target])

return max(start.values()), five_vehicle_timelines
```
